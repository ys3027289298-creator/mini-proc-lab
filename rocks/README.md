# rocks

石子路纹理的种子偏差实验。C 实现，`make test` 跑自检并输出 `artifacts/rocks/`。

## 要解决的问题

同一块石子路，换一个噪声种子后，同一个位点的石子布纹是否还一致；不一致的跨度有多大；
把这段纹理铺到一个小地形起伏上，布纹会不会随地形拉伸；两个独立的噪声模块跑同一份
地形切片，测量结果能否复现。

## 实验设计

- **固定的石子布局**：位置、半径、旋转、轮廓抖动、色阶全部由布局种子 `1337` 生成，
  与纹理种子无关。换种子只换表面颗粒，所以同一位点的亮度差是纯纹理差，不掺布局差。
- **两个纹理模块**：
  - `A` 值噪声 + fBm（`textureA_raw`）
  - `B` 梯度噪声（Perlin 式）+ fBm（`textureB_raw`）

  两者各自实现哈希、八度叠加与插值，不共享纹理代码；共享的只有石子几何。
- **同一位点跨度**：图表面划成 12x8 格点，每格约 20x20 像素。每个像素取全部种子下的
  最大亮度减去最小亮度，得到该像素的跨度；格点内取均值即该位点的跨度。
  超过阈值（默认 mean + 2σ，可用 `--span-limit` 固定）的位点判定为"离谱"，
  在热图上画红框。
- **地形扰动**：一个高斯小丘放在跨度最大的那个位点上。纹理按一阶布幔模型铺到高度场上：
  采样点沿下坡方向偏移 `k * grad H`。该映射的雅可比为 `I - k * Hessian(H)`，
  其奇异值偏离 1 的程度就是布纹的局部拉伸；沿坡滑动本身只是平移，单独记为位移，不算变形。
- **十字线**：格点内最大拉伸超过 `--deform-scale`（默认 0.08，即 8%）的位点，在
  地形面板和变形热图上以十字线标注，最多 32 个。

## 复现性

程序每次运行都会：

1. 用相同布局种子重建一次布局并逐字节比较；
2. 为两个模块各建一份 33x33 高度切片并逐字节比较（两模块消费的是同一份切片）；
3. 两个模块各自独立再跑一遍，比较三组哈希（平铺亮度 / 偏差场 / 布幔亮度）；
4. 比较两个模块的十字线集合与最大拉伸——这两项只依赖地形，应当完全相等；
5. 统计同一位点换种子后的平均亮度差，确认种子确实改变纹理，并计算 A/B 亮度相关系数，
   确认两个模块不是同一个实现换了个名字。

`--check` 只跑这些检查、不写图片，输出与 `noise/`、`terrain/`、`scatter/` 相同的
`名称=1` / `all_ok=1` 格式。

## 输出

| 文件 | 内容 |
|---|---|
| `artifacts/rocks/report.png` | 六面板总览（两个模块、同位点四连跑、偏差热图、贴地纹理、变形热图、指标） |
| `artifacts/rocks/texture_A.png` / `_B.png` | 两个模块的平铺纹理 |
| `artifacts/rocks/span_heatmap_A.png` / `_B.png` | 跨种子亮度跨度，红框为离谱位点 |
| `artifacts/rocks/draped_A.png` / `_B.png` | 贴地纹理，叠加 1 世界单位网格，十字线为超尺度变形 |
| `artifacts/rocks/deform_heatmap_A.png` / `_B.png` | 局部拉伸场 |
| `artifacts/rocks/sites.csv` | 每个格点的跨度、离谱标记、十字线标记、拉伸值 |

热图用非线性色阶：低于峰值 1.5% 的数值视为零（远场数值噪声在这个量级），
其余做 gamma 0.66 提亮。色条按同一映射绘制，面板上注明 `NONLINEAR KEY`。

## 参数

```
--out DIR              输出根目录（默认 artifacts）
--seeds N              纹理种子数，2..32（默认 8）
--span-limit X         离谱阈值，省略则用 mean + 2σ
--deform-scale X       十字线拉伸阈值（默认 0.08）
--drape-k X            布幔强度（默认 0.25）
--bump CX,CY,SIGMA,AMP 手动放置高斯丘；省略则自动放在跨度最大的位点
--modules A|B|AB       生成哪些模块的单独图片（默认 AB）
--check                只跑自检，不写图片
```

## 当前配置下的结果

```
seeds=8  layout_seed=1337  bump=(9.50,0.50) σ=1.00 amp=0.55 k=0.25
span A   mean=0.116  std=0.021  threshold=0.158  absurd=4/96  peak=0.345
span B   mean=0.114  std=0.020  threshold=0.155  absurd=1/96  peak=0.330
deform   scale=0.080  max stretch=0.128  max displacement=0.081  crosshairs=6
```

布局与切片两模块一致；两次独立运行的 PNG 逐字节相同；A/B 亮度相关 0.965（相关但非同源），
换种子平均亮度差 0.044。

边缘位点的跨度天然偏高（视窗被截断，石子只露出一部分），自动阈值因此会把 4 个离谱位点
放在图上边和左边；这是"同一位点在窗口内露出的石子结构不同"的真实后果，不是测量误差。
