# snowmelt

把**日照角与坡向差**折成融雪修正因子，替代"融雪线拉成水平直线"的做法：
雪线在南坡上移、北坡下移，三条基准雪线各渲染一次基准/修正对比。

- `make test`：C 自检（闭式值、数值点积对照、截断、确定性、不对称门槛）
- `make plot`：自检 + 渲染因子场/统计/雪线对比图到 `../artifacts/snowmelt/`

## 1. 修正因子推导

坐标约定：x 朝东、y 朝南、z 朝上。太阳高度角 h、方位角 A（正南 A=0）；
坡面坡度 β、坡向角 φ（下坡方位，朝南 φ=0）。

太阳方向单位向量与坡面向上法向：

```
S = (sin A cos h,  cos A cos h,  sin h)
n = (sinβ sinφ,    sinβ cosφ,    cosβ)      # 法向水平分量 = 下坡方向
```

太阳直射在坡面上的**入射余弦**（天文辐射的核心项，大气透射取常数时融雪能量正比于它）：

```
cos i = S·n
      = sin h cosβ + cos h sinβ [sin A sinφ + cos A cosφ]
      = sin h cosβ + cos h sinβ cos(A − φ)
```

定义**坡向差** Δφ = A − φ，以平坦地面（β=0，cos i = sin h）为基准归一化，
得到融雪修正因子：

```
                cos i              cosβ + tan h · sinβ · cosΔφ
F(β,φ) = max(──────────, 0) = max(─────────────────────────────, 0)
               sin h                        1
```

- 平坦地面 F=1（基准，不修正）；
- 南坡（Δφ=0）：F = cosβ + tan h·sinβ > 1，入射比平地强，融雪加快、雪线上移；
- 北坡（Δφ=π）：F = cosβ − tan h·sinβ < 1，融雪减慢、雪线下移；
  当 tan h·sinβ > cosβ（北坡且坡度超过太阳高度角）时 cos i<0，太阳在坡面背后，截断 F=0；
- 东西坡（Δφ=±π/2）：cosΔφ=0，F = cosβ，仅保留地面投影项。

代码中 `factor_numeric()` 直接做向量点积，`factor_derived()` 用上式，
两者全场逐格点对照：**最大绝对误差 1.2e-7，非背阴区最大相对误差 1e-6**
（门槛 20%，实测偏差比门槛低 4 个数量级）。

## 2. 南北坡不对称性

令同一坡度 β 上的南北因子为 F_s = cosβ + tan h·sinβ、F_n = max(cosβ − tan h·sinβ, 0)。
两者之差与和：

```
F_s − F_n = 2 tan h sinβ          （未截断时，随 h、β 单调增大）
F_s + F_n = 2 cosβ
相对不对称量 R = (F_s − F_n) / (0.5(F_s + F_n)) = 2 tan h tanβ
```

即不对称量由**太阳高度角与坡度的正切之积**决定：正午太阳越低（冬季 / 高纬）、
坡越陡，南北坡融雪差异越大；h=45°、β=25° 的闭式值 R=93.3%（F_s=1.329, F_n=0.484）。

96×96 合成地形上的实测统计（`stats.txt`，太阳 h=45° 正南、灵敏度 K=0.35）：

| 坡向 | 格点数 | 平均 F |
|---|---|---|
| 南坡 | 2372 | 1.3054 |
| 北坡 | 3539 | 0.2751 |
| 东坡 | 1387 | 0.8323 |
| 西坡 | 1804 | 0.8146 |
| 平坦 | 114 | 1.0000 |

- 南北绝对差 1.0303，**南北相对不对称量 130.4%（门槛 20%，通过）**
- 中间基准雪线 z0=1416 m：南坡雪线 1567 m、北坡 1057 m，**南北差距 510 m**

## 3. 雪线修正与渲染

雪线高程按因子线性修正：`z_line(x,y) = z0 · (1 + K·(F(x,y) − 1))`，K=0.35。
取地形高程分位数 0.45 / 0.60 / 0.75 作为三条基准雪线 z0，各渲染一次：

| 雪线 | z0 (m) | 南坡/北坡修正雪线 (m) | 南北差距 (m) |
|---|---|---|---|
| 低（分位 0.45） | 895 | 991 / 668 | 323 |
| 中（分位 0.60） | 1416 | 1567 / 1056 | 510 |
| 高（分位 0.75） | 1645 | 1821 / 1228 | 593 |
