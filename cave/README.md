# cave — 阈值挖洞与连通性分析

3D fBm 密度场（64³ = 262144 格，4 octaves，scale 0.08，seed 42），`density > t` 挖空，
6-邻接 BFS 标记连通域。`make test` 跑自测；`./cave <t>` 单档生成；`./cave sweep` 扫阈值。

## 关系式（阈值 → 连通体积）

开挖体积精确式：**V(t) = N · p(t)**，p(t) 为密度超过 t 的比例。
fBm 边际分布近似高斯，probit 最小二乘拟合（`out/sweep.txt`，RMSE = 0.015）：

```
p(t) ≈ Q((t + 0.0026) / 0.2242)        Q 为标准正态右尾
```

连通率（最大连通域 / 开挖体积）按逾渗强度拟合（临界点 p_c ≈ 0.139，对应 t_c ≈ 0.24）：

```
R(p) ≈ ((p − 0.139) / (1 − 0.139))^0.075   (p > p_c；p ≤ p_c 时仅剩有限尺寸残差 → 0)
```

**连通体积 V_conn(t) = N · p(t) · R(p(t))**。
p < p_c 时实测 R 仍有 0.1–0.3，是 64³ 有限尺寸下"最大碎块"残差，随 N 增大趋于 0；
拟合幂律在临界附近 RMSE ≈ 0.08，远离临界区（p > 0.2）误差 < 0.03。

## 连通性判定代价

- 算法：6-邻接 BFS  flood fill（等价方案：并查集，同为近线性）。
- 时间：每格入队 ≤1 次、每格查 6 邻居 → ≤ 6N 次边检查，**O(N)**；实测 64³ 全量标定
  0.7–1.9 ms（≈3–7 ns/格，随 cave 占比变化）。
- 空间：label 数组 4 B/格 + 队列最坏 4 B/格 + mask 1 B/格 ≈ **9 B/格**（64³ ≈ 2.3 MB），O(N)。
- 结论：连通性判定与生成同阶，可放在每次挖洞后做全量校验；逐次改阈值调参时
  无需增量结构，直接重标定即可。

## 孤岛合并方案（三档孤岛数均不为零，必须处理）

1. **小孤岛回填**：体积 < v_min（建议 100 格）的孤岛直接填回实体。O(N)。
   低档孤岛共 1116 格、仅 1 个超 100 格，回填后基本干净。
2. **走廊打通**：对剩余孤岛，从主连通域出发在实体格上跑多源 Dijkstra，
   代价取 `(t − density)⁺`（穿过越接近阈值的实体越便宜），挖通最小代价路径。
   单次多源 O(N log N)，孤岛逐个并入主域。
3. **自适应降阈值**：二分下调 t 并重标定，O(N log(1/ε))。注意本种子下 t=−0.20
   仍有 26 个孤岛，纯降阈值无法收敛到单连通域，只能作为辅助手段。

推荐组合：**回填（v_min=100）→ 走廊打通剩余孤岛 → 重标定验证 R=1**，
总代价 O(N log N)，与生成同阶。
