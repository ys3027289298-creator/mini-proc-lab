## 抖动幅度与最小间距的可行关系

网格边长 `cell = c`，每格一个点，点位于格心加抖动 `(jx, jy)`，
`|jx|, |jy| <= J`（方形抖动域）。

- 轴相邻两格格心距为 `c`；抖动相向时位移最大，两点能达到的最小距离为
  `d_min(J) = c - 2J`（对角邻居为 `sqrt(2)*(c-2J)`，故轴相邻对是紧约束）。
- 要求任意点对间距不小于 `d`，则抖动上限为

```
J <= Jcap = (c - d) / 2,   J >= 0
```

- 可行域边界：`c >= d`，即密度 `rho = 1/c^2 <= 1/d^2`。
  越过该边界时 `Jcap < 0`，连 `J = 0` 的刚性网格都不满足间距，任何抖动
  幅度都无法挽救——只能靠拒绝采样丢弃点（降低实际密度）。

## 三档密度实测（seed 固定，J 取 Jcap 的 1-1e-5 留浮点余量）

| 档位 | 网格 | c | d | 密度 1/c² | Jcap | 实测最小点距 | 重叠计数 | 拒绝数 |
|---|---|---|---|---|---|---|---|---|
| low    | 8×8   | 1.00 | 0.50 | 1.00  | 0.250 | 0.559951 | 0 | 0 |
| medium | 10×10 | 0.60 | 0.40 | 2.78  | 0.100 | 0.421543 | 0 | 0 |
| high   | 12×12 | 0.40 | 0.30 | 6.25  | 0.050 | 0.311680 | 0 | 0 |

三档目标点全部落位，重叠计数均为 0。

## 失效反例

`c = 0.25, d = 0.30`（密度 16 > 1/d² = 11.11）：`Jcap = -0.025 < 0`，
关系给不出可行抖动。

- 不做拒绝直接放置：144 点全部落位，264 对重叠，最小点距仅 0.25；
- 打开拒绝：只有 72/144 个点能放下，72 个被拒——间距是靠丢弃一半点
  换来的，等价于承认该密度下关系失效。
