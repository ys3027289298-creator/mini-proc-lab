# rockfall — 坡面滚落散布

替代平面抖动散布：石块从坡面起始区释放，沿坡滚落，按坡度 θ 与等效摩擦系数 μ 决定停止距离。

`make test` 跑模拟 + 自检，输出三组统计到 `out/stats.txt`，俯视图到 `out/rockfall_{A,B,C}.svg`。

## 滚落距离分布推导

设石块质量 m（取 1 kg），坡角 θ，等效摩擦系数 μ（含滚动摩擦）。当 **μ > tan θ** 时石块在坡面上减速，最终停在坡面上。

**减速度**：沿坡方向重力分量 mg·sinθ 向下，摩擦力 μmg·cosθ 向上，净减速度

```
a = g (μ cosθ − sinθ)   (> 0)
```

**停止距离**：崩落赋予石块初始动能 E₀，由功能关系 E₀ = m·a·S，得

```
S = E₀ / (m g (μ cosθ − sinθ))
```

**初始动能模型**：崩落能量经两次独立指数级传递（落高转化 + 碰撞分配），故

```
E₀ ~ Gamma(k=2, 尺度 β)，  f(E) = E/β² · e^(−E/β)，峰值在 E = β
```

**距离分布**：Gamma 对正缩放封闭，S = E₀/(m·a) 仍为 Gamma：

```
S ~ Gamma(2, λ)，  λ = β / (m g (μ cosθ − sinθ))
f(s) = s/λ² · e^(−s/λ)
```

- **分布峰值（众数） s\* = λ = β / (m g (μ cosθ − sinθ))**
- 均值 E[S] = 2λ，可用于交叉校验（模拟均值 ≈ 2 × 推导峰值）

方向：沿最大坡度方向，叠加 ±15° 均匀横向扰动。

## 三组参数与推导峰值

| 组 | θ | μ | β (J) | μcosθ−sinθ | s\* = β/(g(μcosθ−sinθ)) |
|----|-----|------|--------|-----------|--------------------------|
| A | 20° | 0.50 | 8.0 | 0.1278 | ≈ 6.39 m |
| B | 30° | 0.65 | 8.0 | 0.0629 | ≈ 12.97 m |
| C | 15° | 0.35 | 12.0 | 0.0793 | ≈ 15.45 m |

## 验收

每组 1024 块石（32×32 抖动网格起始区）。分布峰值用高斯 KDE（Silverman 带宽）在距离轴上取众数；
另以 Gamma(2) 性质 众数 = 均值/2 做交叉估计。两个峰值估计与推导 s\* 偏差均 ≤ 30%，
否则 `make test` 失败（直方图峰值仅作参考打印，256 块时噪声过大，不作为判据）。
