# 坡度图台阶问题：误差推导、最小网格与三档统计

复现：`make analysis`(源码 `src/slope_grid.c`)。

## 1. 流水线与记号

高度场 `z(x,y)` 采样在间距 `h` 的网格上；`field_sample` 做双线性重建，
`field_slope` 用中心差分 (CD) 估坡度。算例悬崖：

```
z(x,y) = A·tanh((x−X0)/W),  L=16, X0=8, A=4, W=0.8
解析坡度 s(x) = (A/W)·sech²((x−X0)/W),  峰值 S_MAX = A/W = 5
```

## 2. 双线性采样误差

对 `z ∈ C²`，双线性插值（沿网格线退化为线性，混合项 `xy` 被精确再现）：

```
|z − I_h z| ≤ h²/8 · (M_xx + M_yy),   M_xx = max|z_xx| 等
```

tanh 悬崖：`M_xx = max|z''| = (A/W²)·max|2·sech²u·tanhu| = 4A/(3√3·W²) ≈ 0.770·A/W²`。
即采样误差 `O(h²)`，悬崖处常数 ∝ `W⁻²`。

## 3. 中心差分坡度误差

Taylor 展开：

```
ĝ = (z_{i+1} − z_{i−1})/(2h) = z′ + (h²/6)·z‴ + O(h⁴)
```

与双线性的关系：双线性面元在节点处左/右斜率分别为
`(z_i−z_{i−1})/h`、`(z_{i+1}−z_i)/h`，CD 恰为两者平均——即"双线性采样 +
中心差分"整条流水线在节点处的误差就是 `(h²/6)z‴`，同为 `O(h²)`。
（离节点处再叠加坡度场的双线性插值误差，同阶。）

## 4. 悬崖处的失效与台阶成因

峰顶 `z‴(X0) = −2A/W³`，故峰值坡度的相对低估：

```
ε_rel(h) ≈ h²·|z‴| / (6·S_MAX) = h² / (3W²)
```

- `h ≪ W`：误差 `O(h²)` 收敛（数值验证：阶数 1.45 → 1.85 → 1.96 → 2）。
- `h ≳ W`：`sech²` 峰宽内不足 2 个采样点，峰被混叠。离散坡度剖面只能取
  `Δz/(2h)` 的少数量化档位——N=16 剖面实测为
  `… 0.067, 0.778, 2.900, 2.900, 0.778, 0.067 …`，相邻像素等值、
  呈平台跳变，即坡度图上可见的台阶。峰值被削平（N=16 实测峰 2.90 vs 真值
  5.00，低估 42%），相对误差 O(1)，不再随 h 收敛。

## 5. 最小可用网格

要求峰区相对误差 ≤ tol：

```
h²/(3W²) ≤ tol   ⇒   h_min = W·√(3·tol)
tol = 0.10, W = 0.8   ⇒   h_min = 0.438
N_min = ⌈L/h_min⌉ + 1 = 38   (h = 16/37 = 0.432 ≤ h_min)
```

## 6. 三档网格坡度统计（实测）

| N | h | 峰值坡度（真值 5.0) | 崖带均值 | err_max | err_rms | 峰值相对误差 | 是否低于最小网格 |
|---|---|---|---|---|---|---|---|
| 16 | 1.0667 | 2.900 | 1.839 | 0.424 | 0.207 | 42.0% | 是 |
| 32 | 0.5161 | 4.106 | 2.457 | 0.408 | 0.118 | 17.9% | 是 |
| 64 | 0.2540 | 4.730 | 2.506 | 0.146 | 0.032 | 5.4%  | 否 |

收敛验证（err_max vs h）：N=16→256，阶数 0.05 / 1.45 / 1.85 / 1.96，
确认 `h ≳ W` 时不收敛、`h < h_min` 后恢复二阶。

## 7. 最小网格以下的台阶像素数

台阶像素判据：局部相对误差 `|ŝ−s| > 10%·s` 且真实坡度不可忽略
(`s > 1%·S_MAX`)；条纹贯通整列，像素数 = 坏列数 × N。

| 网格 | 坏列数 | 台阶像素数 |
|---|---|---|
| N=16 (h=1.067) | 4 | **64** |
| N=32 (h=0.516) | 6 | **192** |

N=64（高于最小网格）台阶像素为 0。注意 N=32 像素数反多于 N=16：
台阶带的物理宽度随 h 缩小，但像素总数按 N² 增长；看占比
(64/256 = 25% vs 192/1024 = 18.75%) 或物理宽度才是正确口径。

## 8. 结论

悬崖坡度图台阶是网格混叠伪影，不是插值 bug：双线性 + 中心差分在
光滑区为二阶精度，但悬崖过渡带宽度 W 给网格尺度设了下限
`h ≤ W·√(3·tol)`。本算例最小可用网格 N=38；N=16、N=32 两档低于
该限，分别产生 64、192 个台阶像素。工程上：按最陡悬崖的 W 选网格，
或对坡度图在渲染前做超采样/光滑，不能靠提高输出分辨率掩盖。
