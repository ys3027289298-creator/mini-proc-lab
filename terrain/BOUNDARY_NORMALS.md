# 高度场边界法线：坡度估计偏差上界与边界处理

## 1. 问题定位

`field_slope()` 旧实现在网格边界把越界下标钳位到边界自身（terrain.c 旧代码）：

```c
int xm = x > 0 ? x - 1 : x, xp = x < W - 1 ? x + 1 : x;
float dx = (h[xp] - h[xm]) / ((xp - xm) * cell);
```

内部节点 `xp - xm = 2`，是中心差分；边界节点 `xp - xm = 1`，差分退化为**一阶单侧差分**，
截断误差由 O(h²) 降为 O(h)。法线 `n = (−fx, −fy, 1)` 由梯度直接构造，梯度偏差原样传播为法线夹角偏差，
因此四条边界上的法线是错的。

## 2. 坡度（偏导）估计的偏差上界

记网格尺度 `h = cell`，`M_k = max |f^(k)|`（在差分模板覆盖区间内取最大）。

### 2.1 内部：中心差分（不变）

泰勒展开：

```
D0 f = [f(x+h) − f(x−h)] / (2h)
      = f′(x) + h²/6 · f‴(x) + O(h⁴)
```

偏差上界：

```
|e_in| ≤ M3 · h² / 6                                       (1)
```

### 2.2 旧边界处理：退化的前/后差分

```
D+ f = [f(x+h) − f(x)] / h
      = f′(x) + h/2 · f″(x) + h²/6 · f‴(x) + O(h³)
```

偏差上界：

```
|e_old| ≤ M2 · h / 2 + M3 · h² / 6 + O(h³)                 (2)
```

主导项是 **O(h)**，系数含 `M2`。只要边界处二阶导不为零，边界偏差就比内部大一个网格阶数，
不存在与内部同阶的 O(h²) 统一上界——这就是边界法线错误的根源。

### 2.3 新边界处理：三点二阶单侧差分

西/南边界（前向）与东/北边界（后向）：

```
D_f = [−3f(x) + 4f(x+h) − f(x+2h)] / (2h)
D_b = [ 3f(x) − 4f(x−h) + f(x−2h)] / (2h)
```

泰勒展开（前向为例）：

```
D_f = f′(x) − h²/3 · f‴(x) − h³/4 · f⁗(x) + O(h⁴)
```

偏差上界：

```
|e_bnd| ≤ M3 · h² / 3 + M4 · h³ / 12 + O(h⁴)              (3)
```

主导项恢复为 **O(h²)**，与内部 (1) 同阶，系数恰为内部的 2 倍。
模板要求边界内侧至少还有 2 个网格点（`W, H ≥ 3`）。

## 3. 梯度偏差到法线夹角的传播上界

高度场曲面 `z = f(x,y)` 的单位法线取

```
n = (−fx, −fy, 1) / sqrt(1 + fx² + fy²)
```

设解析梯度 `∇f*`、估计梯度 `∇f = ∇f* + eg`，记

```
ε = |eg|,  s = |∇f*|
```

高度场法线（未归一化）为 `N* = (−∇f*, 1)`、`N = N* + (−eg, 0)`，
归一化后 `n* = N*/|N*|`、`n = N/|N|`。由叉积恒等式
`n* × n = (N* × N)/(|N*||N|)`，且 `|N* × N| = |N* × (−eg,0)| ≤ |N*|·ε`：

```
sin θ = |n* × n| ≤ ε / |N|
|N| = sqrt(1 + |∇f|²) ≥ sqrt(1 + (s − ε)²) ≥ 1 − sε
```

故法线夹角上界为

```
sin θ ≤ ε / (1 − sε)
θ ≤ α = asin( ε / (1 − sε) ),   适用条件 ε(1 + s) < 1      (4)
```

二维梯度两个分量分别套用 (1)/(3)，令

```
ε_in  = h²/6 · sqrt(M3x² + M3y²)          （内部）
ε_bnd = h²/3 · sqrt(M3x² + M3y²)          （新边界处理）
```

代入 (4) 即得内部/边界各自的法线夹角上界。旧边界处理因 (2) 含 `M2·h/2` 项，
只能给出 O(h) 的夹角上界，网格加密时收敛速度慢一阶。

## 4. 上界的适用网格尺度

(1)(3)(4) 是**截断误差上界**，成立还要求：

1. **模板宽度**：边界单侧三点模板需要 2 个内点，即 `W, H ≥ 3`；
2. **光滑性**：`f` 在模板跨度（边界为 2h）内三阶可导，`M3、M4` 在该区间取值；
   h 须远小于地形特征尺度 L，使三阶导在局部有界且稳定；
3. **舍入误差地板**：浮点差分的舍入项约为 `2u·A/h`（A 为高度幅值，u 为机器精度），
   截断项 `M3·h²/3` 必须显著大于舍入项：

   ```
   h ≫ h_floor = (6uA / M3)^(1/3)
   ```

   float32（u≈5.96e−8）、本实验室表面 A≈50、M3≈0.12 时 `h_floor ≈ 0.053`；
   float64（u≈1.11e−16）时 `h_floor ≈ 3.0e−4`。h 低于该地板后 (3)(4) 不再保证成立；
4. **夹角上界条件**：`ε(1+s) < 1`，中等坡度且 h 处于上述有效区间时自然满足。

## 5. 验证方案

解析三次曲面（三阶导为常数，泰勒高阶项精确消失，(3) 式成为紧上界）：

```
f(x,y) = 0.01x³ + 0.02y³ + 0.3x² + 0.4y² + 0.1xy + 1
fx      = 0.03x² + 0.6x + 0.1y          fxxx = 0.06
fy      = 0.06y² + 0.8y + 0.1x          fyyy = 0.12
```

16×16 网格、h = 0.5（域 [0, 7.5]²）。边界单侧上界分量
`εx = h²/3·0.06 = 0.005`、`εy = h²/3·0.12 = 0.010`。
在西/东/南/北四条边界各取一点，比较旧 O(h) 处理与新 O(h²) 处理相对解析法线的夹角，
并按 (4) 判定：**新方法夹角超过上界即判未完成**。另做 h = 1.0 / 0.5 / 0.25 收敛阶实验。
