# terrain

`make test` 跑自检（`terrain` 高度场基础 + `stitch` 多种子无缝拼接验证）。

## 无缝拼接边界条件推导

设相邻两 tile 在共享边 Γ 两侧的高度函数为 H_A、H_B，表面法线
**n** = (−∂h/∂x, −∂h/∂y, 1)/√(1+|∇h|²)。不同种子直接拼接的"断层"来自以下两条之一：

- **C0（高度连续）**：∀p∈Γ，H_A(p) = H_B(p)。离散化 ⇒ 共享边顶点逐位相等
  `h_A[W-1][y] ≡ h_B[0][y]`，否则网格在缝处开裂。
- **C1（法线连续）**：∀p∈Γ，∂H_A/∂n = ∂H_B/∂n。切向导数由 C0 自动保证
  （沿边差分用的是同一组共享顶点）；法向导数不匹配则两侧法线有折角，光照出现亮暗缝。

### 构造（`src/stitch.c`）

所有 tile 采样同一个全局拼接函数：

```
H(p) = Σ_k w_k(p)·N_k(p),   Σ_k w_k(p) ≡ 1,  w_k ∈ C¹
```

N_k 是第 k 块自己种子的 fBm；w_k 是 smoothstep 划一权，在相邻 tile 间 μ=25%
宽度内交叠（`smooth01(t)+smooth01(1−t)=1` 保证权和恒为 1）。共享顶点无论由哪块
求值都是同一串浮点运算 ⇒ **C0 位精确**；H 整体 C¹ ⇒ 用跨缝幽灵层（ghost layer）
中心差分求法线时两侧**位精确一致**。每块内部夹紧差分（`field_slope` 同款）的
残差只是 O(κ·cell) 截断误差，与 C1 是否成立无关。

## 阈值依据

| 指标 | 阈值 | 推导 |
|---|---|---|
| 接缝高度差 Δh | 1e-6·AMP | 构造上位精确为 0；容差仅留浮点舍入余量：float eps≈1.2e-7 × \|h\|max(≈AMP)，向上取整 |
| 法线夹角（ghost，跨缝真值） | 0.02 rad = 1.146° | Weber 定律人眼亮度可辨差 ≈2%；漫反射 L∝**n**·**l**，ΔL/L ≤ \|Δ**n**\| ≈ Δθ(rad) ⇒ Δθ ≤ 0.02 rad |
| 法线夹角（clamped，单 tile 渲染残差） | 1.5·κ·cell | 前/后向差分截断误差各 ≤ (cell/2)·κ，两侧之差 ≤ κ·cell；κ 为全局最大二阶导（中心二阶差分实测），1.5 为采样欠估计安全系数。此项只证明残差全部来自离散截断而非 C1 破坏 |
