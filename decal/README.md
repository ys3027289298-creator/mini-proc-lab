# decal

悬崖下的草贴花：用**表面梯度**推导贴花的变形矩阵，按法线失活，在三面垂直悬崖上各贴一次，并给出三档拉伸指标与表面展开图。

`make test` 跑自检（26 项），同时在本目录生成 `unfolding.svg`。

## 1. 从表面梯度到变形矩阵

地形是高度场 h(x,y)。一株草贴花在平面上本是参考尺寸 r1×r2 的正方形，
用单位参数域 (u,v) ∈ [0,1]² 经

r(u,v) = ( x0 + r1·u, y0 + r2·v, h(x0 + r1·u, y0 + r2·v) )

贴合到表面。对 u、v 求偏导（链式法则），变形矩阵（雅可比）的两列直接由表面梯度 ∇h=(hx,hy) 给出：

```
        ⎡ r1      0   ⎤
J(r) =  ⎢  0     r2   ⎥
        ⎣ r1·hx  r2·hy ⎦
```

列向量 `c1 = r1(1,0,hx)`、`c2 = r2(0,1,hy)`。单位贴花 r1=r2=1 时即 `J=[(1,0,hx);(0,1,hy)]`。

### 右柯西-格林度量与主拉伸

贴花被拉伸的全部信息在右柯西-格林张量里：

```
C = JᵀJ = ⎡ r1²(1+hx²)     r1r2·hxhy     ⎤
          ⎣ r1r2·hxhy       r2²(1+hy²)    ⎦
```

以贴花原尺寸 D=diag(r1,r2) 归一化，得到相对于贴花原状的度量 `C' = D⁻¹ C D⁻¹`，
其特征值平方根即两个**主拉伸**（雅可比奇异值的归一化形式），最大者记 smax。

## 2. 三档贴花拉伸指标

每个贴花报告三个指标（`Stretch`），再加与坐标轴无关的主拉伸 smax 用于分级：

| 指标 | 定义 | 含义 |
|---|---|---|
| s_u | √C'₁₁ | 沿参数 u 方向的拉伸倍数 |
| s_v | √C'₂₂ | 沿参数 v（崖壁向下）方向的拉伸倍数 |
| s_area | ‖c1 × c2‖ / (r1·r2) | 面积拉伸倍数 |

分级阈值（取 smax）：

```
OK    smax ≤ 1.5
WARN  1.5 < smax ≤ 2.5
OVER  smax > 2.5     ← 拉伸超过极限，必须标出所在面
```

### 连续面的闭式结果

45° 缓坡 hx=0, hy=1：等高线方向 s_u=1，下坡方向 s_v=√(1+|∇h|²)=√2，面积 √2。
平面 ∇h=0：J 为单位阵，三项指标全 1。

## 3. 法线失活：只在法线接近水平时失活

由梯度直接得单位法线：

```
n = (−hx, −hy, 1) / √(1+hx²+hy²)，其竖直分量 n_z = 1/√(1+|∇h|²)
```

失活规则：**仅当法线接近水平**，即 n_z < cos70° ≈ 0.342（坡度角 > 70°）时贴花不投影。
缓坡 45° 的 n_z≈0.707 > 0.342，贴花保持激活；垂直墙面 n_z=0，失活。

## 4. 垂直悬崖：3×2 映射退化与墙面参数化

垂直阶跃处高度场不连续，∇h→∞，第 1 节的高度场参数化退化。
墙面仍是高度场的分段线性部分，改用显式墙面参数化：取墙顶水平单位切线 t 与墙面外法线 n3（水平），

```
r(u,v) = rim + L·u·t − H·v·n3，   J = [ L·t | −H·n3 ]
```

L 是贴花原边长（参考尺寸），H 是墙高。t⊥n3 故两列正交：
沿墙宽 s_u = L/L = 1，沿墙向下 **s_v = H/L**——这就是"沿崖壁往下拉"的倍数；
面积 s_area = H/L。本场景墙高 H=6，三面墙各贴一次，靠不同贴花尺寸 L 落到三档：

| 面 | 外法线 | L | s_v = H/L | smax | 档位 |
|---|---|---|---|---|---|
| 北墙 N (y=10) | +y | 4 | 1.50 | 1.50 | OK |
| 西墙 W (x=6)  | −x | 3 | 2.00 | 2.00 | WARN |
| 东墙 E (x=10) | +x | 2 | 3.00 | 3.00 | **OVER** |

超限贴花在自检输出与展开图中都标出所在面：`over_limit_faces=E`。

## 5. 场景

解析分段高度场（台地世界坐标 x,y∈[6,10]，顶高 6m）：

- 北/西/东三面是垂直阶跃悬崖（真不连续，跨面单侧差分给出大梯度佐证，失活用墙面显式法线 n_z=0）；
- 南面是连续 45° 斜坡（h=y，|∇h|=1），贴花不失效；
- 其余为平地。

## 6. 展开图 `unfolding.svg`

各面以真实边长摊平到纸面（铰链边等长）：顶面居中，北/西/东墙沿各自铰链向外摊开，南坡摊在南侧。
每面内的贴花矩形高度 = L × s_v，直观显示"往下拉"的量。

三档用固定 status 色 `#0ca30c / #fab219 / #d03b3b`，并同时给符号（✓ / ! / ✕）与 45° 斜纹，
颜色不单独承载信息（色盲/打印兜底）；OVER 的东墙 E 用粗红框 + 警示框醒目标注所在面。
