# hydrology

基于流量累积的五要素连通水系生成，纯 C、无外部依赖。

`make test` 跑 18 项自检并在 `out/` 落四份产物；`./hydrology <seed>` 换地形种子，
`./hydrology sweep` 连跑 50 个种子做连通性稳定性扫描，`./hydrology debug` 打印坡降分布。

## 管线

1. 值噪声 + fBm 合成 80×80 高度场，叠加区域坡降、蜿蜒河谷槽、两条确定性断层崖（瀑布成因）。
2. **priority-flood 填洼**（Wang–Liu 风格最小堆）：所有洼地填到可溢出高程，全图只保留一个强制出口，
   每个单元得到唯一 D8 下游，从构造上消灭孤立圆坑。
3. **流量累积**：按高程降序把单元累积量传给下游；同时算 Strahler 级数。
4. **五要素分类**：
   - 支流 `acc >= 60`、主河道 `acc >= 320`（阈值见源码顶部，可调）；
   - 湖泊 = 填洼高程高出原始地面 > 0.15 的湖床，并沿 D8 雕刻溢流通道，保证湖泊必有出口；
   - 瀑布 = 河道骨架上、坡降 > 0.15 且确有上游水体汇入的陡坎（不悬空）；
   - 沼泽 = 原始地形坡降 < 0.04、只接受湖水/滞水补给、且 D8 排水不离开湿地的有限漫流区。
5. **实例化**：河道类（主河/支流/瀑布）按同类 D8 连续链计实例；面状类（湖泊/沼泽）按 8 邻域斑块计。
6. 建链间有向图（D8 顺接边 + 8 邻域侧渗边分开统计），跑连通性审计。

## 输出（out/）

| 文件 | 内容 |
|---|---|
| `report.txt` | 五要素三项统计、逐实例明细、吸收统计、要素间衔接矩阵、断头审计 |
| `grid.txt` | ASCII 栅格：`#`主河 `+`支流 `~`湖 `:`沼泽 `v`瀑布 `O`出口 |
| `map.ppm` / `map.svg` | 彩色地图，SVG 带图例与断头红叉标注 |

## 连通性判据

- 每条 D8 链要么有 D8 下游水体、要么到达唯一出口；
- 33 条支流链 100% 并入主河，低于阈值的陆面细沟 100% 被首个水系单元吸收（无悬空水流）；
- 审计列出的断头分五类：孤立水体 / 下游消失在陆面 / 瀑布悬空 / 湖泊死水 / 支流未并主河，
  每条给出末端坐标、缺失要素和沿流向的路径。当前 50 个种子扫描全部 `breaks=0`。
