# vibfield

低海拔地形纹理会在高度图上制造**伪震动**（细粒度噪声被坡度/曲率分级误判为
ACTIVE）。本模块把高度图转成预测振动状态，按振动格密度把频率线性外推到
核心区外围的缓冲区，列出越过频率告警阈值的缓冲区格子，并对每个越界格做
落石检查。

`make test` 跑自检（15 项 `check`），`make runs` 输出十轮机器可读记录。

## 流水线

1. **高度图** `height_build`：40×40 核心区。宏观地形固定——缓坡
   （坡度 ~0.12）与一条 7 m 落差、2.5 格宽的斜向陡崖带交叉；低海拔区
   （谷底以上 `Z_LOW=2.2`）叠加每轮换种子的双层 fBm 细纹理，海拔越高
   纹理幅度越小。外围 4 格为缓冲区，工作网格 48×48。
2. **3×3 平滑** `smooth3`：剥离细纹理，得到结构场 `sm`；无纹理基准地形
   另存 `base`，专供落石判定。
3. **状态分级** `states_build`：按平滑场坡度/曲率分 CALM / GENTLE /
   ACTIVE / CLIFF。原始场判 ACTIVE+ 但平滑后 ≤GENTLE、位于低区、且
   高度残差 ≥ `R_TEX` 的格子标记 `pseudo` 并抑制为 CALM——这就是
   纹理伪震动，不是结构性振动。
4. **密度** `density_build`：5×5 窗口内 ACTIVE+ 格占比 ρ。
5. **外推** `density_extrapolate`：取边界两层密度差作为梯度，线性外推
   到缓冲区边界。振动密度不可能背离源增长，所以外推梯度钳为 ≤0、密度
   钳在 [0,1]，外推首格与边界值相等（无跳变）。
6. **频率** `frequency_build`：`f = F_BASE + K_RHO·ρ`（1 + 12ρ Hz），
   缓冲区密度低于 `RHO_MIN` 视为静默。`f > F_ALARM (4.5 Hz)` 的缓冲区
   格即**越界格**。

## 落石检查的具体步骤

对每个越界格，取其最近的核心格为"源格"，依次过四道门，**全部为真才判
落石风险**（`rockfall_check`）。前三道只读无纹理基准场 `base`，因此结论
与纹理种子无关：

| 门 | 字段 | 判定 |
|---|---|---|
| 1. 崖面 | `s1` | 源格在基准地形上的坡度 ≥ `S_CLIFF (1.5)`，确为陡崖面 |
| 2. 外向下坡 | `s2` | 沿越界方向，内侧相邻格基准高度高于源格——岩石向外滚 |
| 3. 通道追踪 | `s3` | 从源格向内追踪 3 格，基准高度严格单调上升且每格坡度 ≥ `S_BLOCK (0.12)`，无平底阻拦区 |
| 4. 频率余量 | `s4` | 外推频率 > `F_ALARM`（越界格本身满足，留作显式门） |

## 两种运行模式

- `FILTERED`：默认，启用伪震动抑制。
- `RAW`：信任原始高度图，不抑制。对照用——RAW 会把纹理驱动的振动也
  外推进缓冲区，产生假警报（十轮中比 FILTERED 多 28 个越界格）。

## 输出格式

```
RUN,<轮>,<种子>,<越界格数>,<抑制伪震动格数>
OOB,<轮>,<r>,<c>,<边界 N/S/W/E>,<外推距离>,<ρ>,<频率Hz>,<源状态>,<s1>,<s2>,<s3>,<s4>,<落石风险>
```

十轮重复率聚合：

```
make runs
python3 -I tools/repeat_report.py <filtered.csv> <raw.csv> <report.md>
```

报告与逐格明细（`*_cells.csv`）写入 `../artifacts/`。关键结论：24 个
落石格十轮 10/10 复现（结构性），普通越界格随纹理种子漂移，整体平均
重复率 92.4%。
