# props

静物（轴对齐包围盒）在高度场上的偏移高度层。`make test` 跑自检并输出三档统计与对比图（默认写到 `out/`，可 `./props <dir>` 指定）。

## 问题

静物底面直接放在锚点（包围盒中心）采样的地形高度 `h₀ = h(cₓ, c_y)` 上。坡地上包围盒覆盖区域 `R` 内地形起伏不为零，高点穿过底面 → 静物被埋；光照只采裸地形层，看不到静物，阴影长度也按错的层计算。

## 偏移推导

设包围盒底面矩形 `R = [cₓ−w/2, cₓ+w/2] × [c_y−d/2, c_y+d/2]`，地形双线性高度场 `h(x,y)`。给静物加一层偏移 `Δ`，底面高度 `base = h₀ + Δ`。

- **下界（不埋）**：要求 `base ≥ max_R h`。若 `Δ < max_R h − h₀`，则 `R` 内最高点处地形高于底面，静物被埋。
- **上界（不悬空）**：要求底面与地形接触，即 `min_R (base − h) = 0`。若 `Δ > max_R h − h₀`，则 `base − h ≥ Δ − (max_R h − h₀) > 0` 在 `R` 上处处成立，脚底悬空。

两界夹出唯一可行值：

```
Δ = max_{(x,y)∈R} h(x,y) − h(anchor)
base = max_R h        —— 底面恰好落在 footprint 最高点，接触间隙为 0
```

**精确求 max_R h**：双线性面片内部唯一驻点是鞍点（Hessian 不定），沿轴对齐边界是线性的，所以凸多边形上的最大值必在顶点取得。候选点集 = `R` 的角点 ∪ 网格顶点∩`R` ∪ 网格线与 `R` 边界的交点（候选 x 集与候选 y 集的笛卡尔积），逐一采样取最大即为精确值，见 `rect_max()`。

## 验证

- 三档尺寸 S(1.2×1.2×0.8) / M(2.6×2.2×1.6) / L(5.0×4.0×3.0)，每档 4 个实例。
- 自检：`offset_is_exact_max`、`not_buried_after`、`feet_not_floating`（任一物体接触间隙 > 1e-4 即失败）、`deterministic`。
- 阴影长度：从物体顶面中心沿光线方向步进求与地形的交点，从 footprint 边界量到阴影尖端。
- 对比图：`compare_top.ppm`（左：修正前，光照采裸地形层；右：修正后，光照采地形+静物合成层）、`compare_side.ppm`（上：埋在坡里；下：落在偏移层上）。
