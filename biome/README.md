# biome

带宽自适应的群系过渡带。旧做法把过渡带宽度写死:带宽混合不自然、窄了割裂。
这里让带宽 `w`(像素)同时驱动两条可解析预测的函数:

## 模糊度关于带宽的函数

带内混合权重走 smoothstep `s(t) = t²(3−2t)`,逐像素模糊指标
`φ = 4s(1−s)`(纯群系为 0,带心为 1)。

- 连续解析预测:`F_c(w) = (18/35)·L·w/P`,其中 `18/35 = ∫₀¹ 4s(t)(1−s(t))dt`,
  `L` 为符号翻转边统计的边界长度,`P` 为总像素数。细带(w=1,2)像素化使连续积分失准,
  误差在 `sweep.csv` 留档,不作为门槛判定项。
- 精确离散预测:对 Felzenszwalb 距离变换得到的排序距离场(纯几何常量、不经过渲染代码)
  直接积分定义式 `F_d(w) = (1/P) Σ_{|d|≤w/2} φ(smoothstep(1/2+d/w))`,
  对 `w` 仍是纯函数,与渲染各自独立实现、浮点级一致。

## 噪声查找次数关于带宽的增长

带内每像素 `(w+1)` 次 value noise tap(1 个主 tap + `w` 个沿偏移细节 tap),
带外 0 次:

- `G_c(w) = (w+1)·Lw` —— 对带宽是二次增长(连续近似,大带宽截断误差增大)
- `G_d(w) = (w+1)·B(w)`,`B(w)` 为距离场二分得到的离散带内像素数,与实测计数精确相等

## 判定口径

模糊度对**任一适用预测**的相对偏离 > 15% 判未完成。实测结果(种子 11、256² 网格):

- 离散预测 F_d/G_d:w=1..12 偏离恒为 0.00%(独立代码路径 + phi 二进制交叉核对 3.7e-9)
- 连续预测 F_c:w≥4 最大偏离 12.62%(PASS);w=1,2 为 63.9%/27.8%,细带像素化所致,留档
- 最割裂区段:`worst.csv` Top10,首点 (196,140),窄带 w=2 邻域最大 RGB 色距 89.83

## 用法

```
make test            # 自测(含 15% 偏离门槛、距离变换精度、计数精确性)
make gen             # 扫描 w=1..12,产物写入 ../artifacts/biome
python3 tools/analyze.py ../artifacts/biome   # 门槛判定、权衡曲线、三档对比图
```

`gen` 产物:`sweep.csv`(逐带宽实测/预测与相对偏离)、`meta.csv`、
`render_w{2,6,12}.ppm`、`phi_w{2,6,12}.f32`、`worst.csv`(最割裂区段 Top10)。
`analyze.py` 另产出四张 PNG、`fuzz_stats.csv`(表视图)与 `verdict.txt`(结论),
门槛失败时退出码为 1。
