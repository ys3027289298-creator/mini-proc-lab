# 等高线线宽 ↔ 噪声梯度 ↔ 八度数：两种噪声基的对齐分析

同一山体窗口（16×16 世界单位，2048×2048 网格，cell = 0.0078125），用两个噪声基
各生成 fBm 高度场：

| 基 | 实现 | 插值核 |
|---|---|---|
| **value**（基 A） | `noise/src/noise.c` 的值噪声，NumPy 逐点移植（C/Python 最大偏差 1.2e-7） | smoothstep `3t²−2t³` |
| **gradient**（基 B） | 同族哈希的 Perlin 梯度噪声 | quintic `6t⁵−15t⁴+10t³` |

两基共用 `noise.c` 里的**幅度归一化 fBm**：`F = Σ rⁱnᵢ(Lⁱx) / Σ rⁱ`，
本实验取 lacunarity `L=2`、gain `r=0.5`、等高线 level ∈ {−0.25, 0, +0.25}。

## 1. 线宽折算成梯度幅值

等高线按固定水平带 `|F − level| ≤ δ` 成色带（本实验 δ=0.08916，按 99 分位
梯度设定并封顶，保证相邻色带不合并）。在等高线附近把 F 一阶展开：

```
F(p) ≈ level + ∇F·(p − p₀)
```

沿法线方向 `n = ∇F/|∇F|`，色带边界满足 `|∇F|·d = δ`，故**全宽**

```
w = 2d = 2δ / |∇F|          ……(1)
```

即：δ 固定时，线宽与梯度幅值严格成反比——"细的那条发虚"等价于"那个基在该
配置下 |∇F| 更大"。

**实测验证（表 1 最后一列 = 2δ/(w·|∇F|)，理想值 1.000）。** 宽度用色带掩码的
欧氏距离变换在 marching-squares 等高线采样点上量取 `w=2·d_EDT`（几何法，
不受等高线曲率影响；沿固定法线行走的方法在弯曲等高线上会因法线发散高估宽度，
已弃用）。解析斜面 `F=1.35x+0.82y` 上比值 1.036（像素量化误差），独立的最近邻
EDT 交叉口径与主测量相差 1.4%。

## 2. 梯度幅值与八度数的对应关系

设第 i 个八度单噪声 nᵢ 的梯度 RMS 为 q₀（由晶格核决定，与 i 无关），则其对
梯度 RMS 的贡献按频率 Lⁱ 缩放、按幅度 rⁱ 加权：

```
qᵢ = q₀ (Lr)ⁱ
```

八度间近似独立，归一化 fBm 的梯度 RMS 为

```
        √( Σ_{i=0}^{N−1} qᵢ² )     √( Σ (Lr)^{2i} )
G(N) = ───────────────────── = q₀ · ─────────────────
            Σ rⁱ                        Σ rⁱ          ……(2)
```

`s = q₀·(常数)` 为逐基自由尺度，吸收晶格梯度 RMS 与归一化常数。Lr=1（本实验
L=2, r=0.5）时有限和形式直接适用，无退化。实测 G(N) 对 (2) 的最大相对误差：
value **1.74%**、gradient **1.50%**（N≤5 无混叠区间），定律成立。

实测 G_rms（全场，世界单位）：

| N | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| value | 1.098 | 1.019 | 1.068 | 1.150 | 1.243 | 1.325 |
| gradient | 1.092 | 1.034 | 1.077 | 1.155 | 1.237 | 1.300 |

拟合尺度 `s_value=1.0786`、`s_gradient=1.0881`——两基本征梯度几乎相同
（差 0.9%）。注意 Lr=1 时 (2) 中分子 ~√N、分母 ~N，**G 随 N 增长很平缓**
（N: 1→6 只增 ~21%），这是归一化 fBm 的固有性质。

## 3. 用该关系对齐两个噪声基

以 value N=6 为基准，其梯度 `G_target = G_value(6) = 1.342`。对基 B 数值反解
`G_gradient(N*) = G_target`：

```
N* = 5.88（连续解）→ 取整 N* = 6
```

即把梯度基从错配的 N=2 重新八度化到 N=6。对齐前后六条等高线的实测宽度：

## 4. 频谱斜率：推导值与实测值并列

八度幅度按 `rⁱ = L^{−αi}` 衰减，定义幅度指数

```
α = −ln r / ln L = 1.00          （r=0.5, L=2）
```

各向同性二维场的径向功率律 `P(f) ∝ f^{−β}`，二维环带能量 ∝ f·P(f) 给出

```
β(2D) = 2α + 2 = 4.00            （注意：1D 谱才是 β=2α+1）
```

实测用两种独立方法，并先用**已知 β 的合成各向同性场校准 FFT 估计器**
（β=2/3/4 的实测偏差仅 −0.009 / −0.015 / −0.019，估计器本身无系统偏差）：

### 表 2：频谱斜率推导值 vs 实测值

| 基 | α 推导 | α 实测（八度梯度 RMS 拟合） | β 推导 (2D) | β 实测（径向 PSD） | β 实测（由 α 换算 2α+2） |
|---|---|---|---|---|---|
| value | 1.000 | **1.022** | 4.000 | **4.107** | 4.044 |
| gradient | 1.000 | **1.049** | 4.000 | **4.031** | 4.098 |

结论：

1. 两基的实测斜率都与"白噪晶格 + r=0.5 归一化 fBm"假设的推导值（α=1，
   β=4）吻合在 ~0.1 以内，**没有出现假设失效**——对齐后残余的线宽不一致
   来自整数八度取整与 s 的尺度差，而非频谱斜率不同；
2. value 基的 β 略陡（4.11 vs 4.03），与其 smoothstep 晶格核在单八度内的
   高频滚降比 quintic 梯度核更快一致，差别仅 0.08，不足以推翻 α=1 假设；
3. 若某基实测 β 明显偏离 4（比如 gain 被改成 0.65 → α=0.62 → β=3.24），
   则 (2) 中的 qᵢ 比例不再是 (Lr)ⁱ，按本实验流程拟合出的 G(N) 定律误差会
   同步放大，对齐时必须改用该基实测 α 重算 qᵢ 序列——这是"斜率与假设不同"
   的可观测信号。
