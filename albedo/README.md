# albedo

把一幅 albedo 贴图拆成**结构层**和**微噪声层**，每层各自的缩放系数互不串扰；
并把这套分层放到三种天气的渲染里，测量每层的幅值范围、截断位置，以及两层同时开启时的交叉项。

```
make test     自检（正交性、截断、天气管线的一致性）
make build    生成 out/*.csv 与 out/*.ppm
python3 tools/figures.py    把 PPM 转 PNG 并绘制 out/fig/*.png
```

## 模型

在线性反射率对数域做分解（分解本身只需一次高斯模糊）：

```
L  = log A                         光学密度
S  = gauss(L, σ)                   结构层：材质、宏观明暗
m  = L - S                         微噪声层：细粒，零均值
A  = clamp( exp( S' + m' ), … )     S' = S̄ + k_s (S − S̄)，m' = clamp(k_m m)
```

两层是同一个滤波拆出的两半，在对数域相加，所以在构造上正交：
转动 k_s 不会改变 m 的幅值，转动 k_m 也不会改变 S 的幅值。
乘性（对数域）分解还让 m 变成**相对**量——k_m 加 20% 就是任意材质上反射率都加 20%，
这正是“微噪声”的含义，也让两个旋钮真正互相独立。
线性域的加法分层做不到这一点：细部存的是绝对量，抬高结构层就会把相对微对比度稀释掉
（`make test` 里的 `additive_layering_cross_talks` 复现了这个失败）。
合并成单层（现状）就更糟：一个系数同时缩放两个频带，没有任何办法只动其一。

## 尺度选择

拆分层级 σ 不是拍脑袋定的，见 `out/scale_decision.csv`（解析高斯传递）与
`out/scale_scan.csv`（实测高通带三通道相关系数）：

| 判据 | 要求 | σ = 2.75 px 时 |
|---|---|---|
| 结构层保留 28 px 细纹理（最细的人工结构） | ≥ 80 % | **82.7 %** |
| 微噪声层保留 3 px 与 1.5 px 细粒 | ≥ 99 % | **100 %** |
| 1.5 px 细粒泄漏进结构层 | 尽量小 | 0 % |

σ = 3.0 px 时结构层只剩 79.7 %（不达标），σ = 2.5 px 时仍达标但切得更靠内；
2.75 px 是满足两条判据的最大值，也即两层分离最大、人工纹理泄漏最小。
实测扫描的旁证：相关系数从 σ=0.5 px 的 0.02 单调升到 12 px 的 0.64，
细粒处三通道各自独立（相关≈0），大尺度才变成三通道共同变化——分界落在 2–3 px 一带。

## 幅值与截断

| 层 | 单位 | 范围（P1–P99） | 硬截断 | 标称增益下截断比例 |
|---|---|---|---|---|
| 结构层 S | 反射率 | R 0.21–0.48，B 0.14–0.47 | [0.030, 0.920] | 0 % |
| 微噪声层 m | 相对 % | −9 % … +10 % | [−12.2 %, +13.9 %] | R 0.12 %，B 0.38 % |

截断位置画在 `out/fig/fig2_amplitudes.png`：结构层要到 k≈1.4 才碰到上限
（B 通道因为雪面偏暖，最早触界；k=1.6 时 B 也才 0.32 %），微噪声层在 k=1 时
R 0.12 %、B 0.38 % 触界，到 k=1.6 升到 5.0 %（R）/ 6.0 %（B）。截断是局部的，不是整幅色调平移——这一点由 `out/truncation.csv`
逐系数给出。

## 交叉项

两层同时开启、只推一层（+20 %），测量另一层同通道的变化（`out/cross_terms.csv`）：

| 天气 | albedo 空间 | 显示空间 | 显示·冻结曝光 |
|---|---|---|---|
| 晴天 | 2.17 % | 0.55 % | 0.50 % |
| 阴天 | 2.17 % | 1.96 % | 1.92 % |
| 黄昏 | 2.17 % | 1.24 % | 1.08 % |

最大一项出在 B 通道。albedo 空间里的 2.17 % 是"重新拆分"带来的测量地板——
抬高结构层后重做一次 `gauss`，滤波自身会漏一点（G·G ≠ G），
按存储层直接测得的正交误差低于 1e-4。
图 3 是放大 30 倍后的交叉项，画面基本是中灰。
对照组（用户原话"压下一个又翘起"）：把 R 通道推 +20 %，看另外两个通道的显示偏差，
合并单层被拖动 1.7–2.0 %（`out/merged_scheme.csv`），分层方案只有 0.01–0.03 %；
单通道推系数时的最大其它通道偏差漂移，合并单层 6.0 %、分层 0.12 %（`out/stability.csv`）。
结构系数推到 +50 %（R/G，
B 在这个量级已触上限）时交叉项升到 3.8 %，仍然没有出现"压下又翘起"的符号翻转。

## 三种天气

固定一套白平衡（中性卡片、中性光下标定一次），三种天气下各通道相对平均亮度的偏差：

| 天气 | R 线性 | G 线性 | B 线性 | R 显示 | G 显示 | B 显示 | 曝光 |
|---|---|---|---|---|---|---|---|
| 晴天 | +6.4 % | −0.5 % | −13.9 % | +2.9 % | −0.1 % | −7.1 % | 0.27 |
| 阴天 | +0.6 % | +0.6 % | −8.1 % | +0.4 % | +0.3 % | −4.5 % | 0.68 |
| 黄昏 | +9.0 % | −5.7 % | +30.3 % | −2.2 % | −1.1 % | +17.0 % | 2.58 |

注意偏色方向会翻转：晴天蓝通道偏冷（−14 %），黄昏蓝通道偏品红（+30 %），
所以"压下一个又翘起另一个"在线性域是字面成立的。

**分层方案在哪里最稳**：阴天。它的线性偏色本来最小（8.1 %），
显示域微噪声幅值三通道最均匀（2.36 / 2.46 / 2.41 ×10⁻²，离散 4.3 %），
单通道 +20 % 引起的另一通道偏差漂移也最小（0.12 %）。晴天居中（显示微噪声离散 24.9 %）；
黄昏最差：曝光被推到 2.58，色调曲线肩部把微噪声层压成三通道严重不均
（12.7 / 7.3 / 3.6 ×10⁻²，离散 251 %），另有 0.5 % 像素已经过曝到显示上限。
也就是说：**天气的光谱越中性、动态范围越窄，两层方案越稳；**
强色温 + 大动态范围（黄昏）下，微噪声层的可见度会随通道和曝光漂移，
此时应先固定曝光/白平衡再做分层调参，否则微噪声旋钮在 B 通道上的实际效果只有 R 通道的 1/3。

综合稳定指数（最大线性偏色 + 分层偏差漂移）：阴天 8.2 %，晴天 14.1 %，黄昏 30.4 %。

## 复现

`make test` 覆盖：

- 两层截面在截断界内、微噪声零均值；
- k_s ±20 % 只移动结构层幅值（误差 < 1e-4），不移动微噪声层；
- k_m ±20 % 只移动微噪声层（误差 < 1 %），不移动结构层；
- 每通道系数只作用于该通道；
- 合并单层把两个频带按同一系数缩放（这是要消除的耦合）；
- 线性加法分层把相对微对比度稀释（反例）；
- 中性平面在固定白平衡下渲染为中性，三种天气输出有限、可复现。
