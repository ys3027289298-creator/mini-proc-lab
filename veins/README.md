# veins

低分辨率矿脉密度场 + 按密度场驱动的泊松采样，替代逐格点独立放岩石的散布方式。
`make test` 跑自检并输出三档目标长度的实验统计。

## 流水线

1. **稀疏锚点**：在粗网格上放 `ANCH × ANCH` 个抖动锚点；
2. **低分辨率密度场**：每个锚点向 `CGW × CGW` 粗节点泼高斯核
   `exp(-d²/(2σ²))`，σ 即平滑尺度；
3. **密度驱动泊松采样**：候选点只在 `密度 ≥ TAU` 的矿脉地面上被接受，
   且与所有已接受点保持最小距离 `R0`，总数硬上限 `NMAX`；
4. **矿脉统计**：以 `RLINK = 1.35·R0` 为连边半径在点集上并查集聚类，
   每个 ≥2 点的连通分量是一条矿脉，长度取分量直径（点对最大距离）。

## 两条定尺度的曲线

σ 太粗，相邻泼斑糊成一条直线带；σ 太细，阈值区域缩成散点。尺度由两条曲线
联合确定，系数在一次未触顶的试跑（σ = `SIGMA0`）上标定：

- 长度—尺度：`L(σ) = cL · σ`
- 采样数—尺度：`N(σ) = min(NMAX, cN · σ²)`

目标长度 `L*` 先由第一条曲线反解 `σ* = L* / cL`，再由第二条曲线读出该尺度
需要的采样数。两曲线交点给出触顶尺度 `σ_cap = √(NMAX/cN)`。

## 采样上限截断

当 `cN·σ*² > NMAX` 时采样数被上限截住：密度场继续变大，但点数填不满，点间
空隙超过 `RLINK`，连通分量断裂。为让触顶后的稀疏均匀作用于每条矿脉（而不是
填满扫描顺序的前半域），候选点采用确定性洗牌顺序访问。

程序对三档目标长度各生成一次，输出三组九个数（每档：矿脉数量、实际平均长度、
最长连续矿脉）。若最长目标档的最长连续段反而最短，打印
`longest_tier_inverted=1` 并把该档**实际尺度与实际采样数并列**输出诊断行。
