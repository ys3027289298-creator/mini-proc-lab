# cloudshade

云厚 → 透光衰减 → 地表辐照度。修复"云影滑过地表但强度不变"：阴影强度由云的光学厚度决定，随云厚场逐格变化。

## 衰减推导

记号：θ 为太阳天顶角，μ = cosθ；z 为地表高程；d 为云几何厚度。

1. **晴空大气消光**。密度随高程指数衰减，消光系数
   β_a(z) = β₀·e^(−z/H)，β₀ = 1.75e−5 /m，H = 8000 m。
2. **斜程光学厚度**。沿光线 ds = dz/μ，从地表 z 积到大气顶 Z（取 30 km）：

   τ_a(z, μ) = ∫ β_a dz/μ = β₀H·(e^(−z/H) − e^(−Z/H)) / μ

   —— 天顶角经 1/μ 进入，高程经 e^(−z/H) 进入（越高大气柱越短，越亮）。
3. **云光学厚度**。云内消光 κ = 0.004 /m 视为常数，斜程云段长 d/μ：

   τ_c(d, μ) = κd / μ
4. **总透过率**（Beer–Lambert）：T = exp(−(τ_a + τ_c))。
5. **地表水平面辐照度**：

   E(d, z, μ) = S₀·μ·exp(−(τ_a(z,μ) + τ_c(d,μ))) + E_diff

   S₀ = 1361 W/m²，E_diff = 40 W/m² 为云下漫射底数。

渲染器不直接用闭式，而是沿斜程对 β(s) 做数值积分（晴空段 256 步中点法 + 云 slab 段独立 128 步中点法——云段只占全程约 1%，混积会欠分辨，曾致 74% 偏差）；自测要求渲染辐照度与上式推导值最大相对偏差 ≤ 15%（实测 ~1e−7）。

简化假设：云为竖直柱（忽略风切/视差偏移），云底固定 2000 m，地表按水平面计（未入地形法线）。
