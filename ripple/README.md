# ripple

风成沙波纹高度场。两个映射彼此独立，各自只吃一个输入：

| 映射 | 输入 | 输出 | 入口 |
|---|---|---|---|
| 风速 → 间距（波长 λ） | 风速 v | 像素波长 | `wavelength()` |
| 风向 → 相位偏移 φ | 风向 θ | 弧度相位 | `phase_from_dir()` |

风向还负责旋转波矢 `(cos θ, sin θ)`，这是纯几何旋转，不进入间距映射。

## 映射推导

### 1. 风速 → 间距

Bagnold 经验关系：沙粒输运存在起动阈值 `V_TH = 4 m/s`，阈值以下不形成
波纹；阈值以上波纹间距随超额风速线性增长：

```
λ(v) = LAM0 + K_LAM · max(v − V_TH, 0)
     = 8 + 3.75 · max(v − 4, 0)        （单位：像素）
```

三档风速对应的理论波长：

| v (m/s) | λ 理论值 (px) |
|---|---|
| 4 | 8.00 |
| 7 | 19.25 |
| 10 | 30.50 |

### 2. 风向 → 相位偏移

相位是只关于风向的加法项，不进入波矢，因此不可能改变间距：

```
φ(θ) = 0.5 · sin(2θ)
```

高度场合成为

```
h(x,y) = 0.8 · sin(2π·(x·cosθ + y·sinθ)/λ(v) + φ(θ))
       + 0.12 · fbm(...)          // 只负责质感，不含主频率
```

## 九组测量结果（fixed，映射独立）

测量方法（`tools/measure.py`）：

- **间距（FFT）**：Hanning 加窗后的频谱主峰，亚像素抛物线插值，
  `λ = N / |f_peak|`。
- **间距（自相关）**：自相关函数沿主峰方向取截面，第一个内部极大值，
  作为实空间交叉验证。
- **主导方向**：频谱峰坐标的 `atan2`，折叠到 [0,180°)。

| 风速 v (m/s) | 风向 (°) | 间距 FFT (px) | 间距自相关 (px) | 实测方向 (°) |
|---|---|---|---|---|
| 4  | 0  | 8.00  | 8.00  | 0.00 |
| 4  | 45 | 7.98  | 7.91  | 45.00 |
| 4  | 90 | 8.00  | 8.00  | 90.00 |
| 7  | 0  | 19.32 | 19.44 | 180.00 |
| 7  | 45 | 19.33 | 19.40 | 45.01 |
| 7  | 90 | 19.33 | 19.44 | 89.99 |
| 10 | 0  | 30.65 | 30.89 | 0.00 |
| 10 | 45 | 30.43 | 30.21 | 44.99 |
| 10 | 90 | 30.65 | 30.88 | 90.01 |

（0° 与 180° 对周期条纹是同一方向，故 v=7/0° 测到 180°。）

独立性判据，全部通过：

- 每个风向下，间距随风速严格单调：8 → 19.3 → 30.6 px。
- 同一风速下三个风向的间距极差 ≤ 0.23 px（亚像素级，来自加窗噪声扰动）。
- 实测方向与请求方向偏差 ≤ 0.01°。

## 耦合是怎么被发现的

`--coupled` 路径故意保留了一个错误版本：间距映射里乘了一个
依赖风向的阵风系数：

```c
/* 耦合来源：风向被塞进了只应由风速决定的间距映射 */
float gust = 1.0f + (0.10f + 0.20f * (speed - 7.0f)) * sinf(3.0f * dir);
lam *= gust;
```

同一张九格表在 coupled 路径下（见 `out/coupled_results.txt`）：

| 风速 v (m/s) | 风向 0° (px) | 风向 45° (px) | 风向 90° (px) |
|---|---|---|---|
| 4  | 8.00  | 5.17  | 12.03 |
| 7  | 19.32 | 20.50 | 17.27 |
| 10 | 30.65 | 45.47 | **9.15** |

- 90° 列间距随 v 走成 12.03 → 17.27 → 9.15，**单调性被破坏**；
- v=10 行同速不同向极差达 36.32 px。

测量脚本据此输出 `COUPLING_DETECTED=yes` 并以非零码退出。
对比两条路径即可定位：单调失败的唯一差异就是 `gust` 这一项——
相位偏移只能平移条纹、改变不了频谱峰的频率，而阵风系数直接缩放了 λ。

**修复**：删掉阵风系数，让 `ripple_lambda()` 在 fixed 路径下只调用
`wavelength(speed)`；风向的全部影响限定为波矢旋转 + 加法相位两处。
修复后同速间距极差回到 ≤ 0.23 px，单调性在三个风向下全部恢复。

## 用法

```
make test       # C 单元自检（映射单调性、方向不变性、确定性）
make matrix     # 生成 fixed / coupled 各 9 张 PGM 并测量，结果存 out/
make montage    # 额外拼两张 3x3 总览 PNG
python3 -I tools/measure.py out/fixed/s07_d045.pgm   # 单张测量
./ripple gen 7.0 0.7854 out.pgm [coupled]            # 单张生成
```

Python 工具用 `-I` 隔离模式运行；numpy/PIL 位于用户 site-packages 时，
脚本会显式补回该路径，cwd 与 `PYTHON*` 变量仍不参与导入。
