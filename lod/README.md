# lod

八度（octave）数量随空间档位变化时的 fBm 过渡模块。三档八度 **3 / 4 / 5**，
硬截断（C0 高度台阶 + 导数棱线）与平滑过渡（C1 连续）两套高度场并排对比。

`make test` 构建并运行 C 自检，同时把高度场、解析导数、边界跳变数据写到
`../artifacts/lod/`；`python3 analyze.py <data_dir> <out_dir> [threshold_deg]`
计算法线夹角统计、判定并出图。

## 1. 八度交界处的导数跳变量推导

值噪声记为 `n_i(x)`，第 `i` 个八度的贡献为

```
q_i(x) = a_i n_i(f_i x),   a_i = gain^i = 2^{-i},   f_i = lacunarity^i = 2^i
```

截断到 `m` 个八度、带归一化的 fBm 为

```
F_m(x) = S_m(x) / A_m,   S_m = Σ_{i=0}^{m-1} q_i,   A_m = Σ_{i=0}^{m-1} a_i
```

`A_m` 是空间常数。在交界处 `x = k`，档位从 `k` 个八度切到 `k+1` 个八度
（本模块 k = 3, 4）。

### 1.1 高度跳变（C0 不连续，来自归一化分母变化）

```
F_{k+1} - F_k = (S_k + q_k)/(A_k + a_k) - S_k/A_k
              = (A_k q_k - a_k S_k) / (A_k A_{k+1})
```

### 1.2 导数跳变（棱线，题目核心）

`A_m` 与位置无关，故 `∇F_m = ∇S_m / A_m`，单侧导数分别为

```
∇F_k  = (1/A_k)   Σ_{i=0}^{k-1} ∇q_i
∇F_{k+1} = (1/A_{k+1}) Σ_{i=0}^{k}   ∇q_i
```

交界处的导数跳变量（向量）：

```
Δ∇F_k = ∇F_{k+1} - ∇F_k
      = [∇q_k - (a_k/A_k) Σ_{i=0}^{k-1} ∇q_i] / A_{k+1}
      = [∇q_k - (a_k/A_k) ∇S_k] / A_{k+1}
```

其中单八度解析导数（值噪声 smoothstep 插值 `u(t)=3t²-2t³`，`u'=6t(1-t)`）：

```
∇q_i = a_i f_i · ∇n_i(f_i x)
```

法线跳角（单侧法线 `n_m = (-Z·∇F_m, 1)/|·|`，Z 为垂直夸张系数）：

```
θ_k = arccos( n_k · n_{k+1} )
```

关键结论：**硬截断在交界上同时产生高度台阶和导数跳变**；导数跳变量与
`∇q_k`（第 k 八度自己的斜率）同阶，八度频率 `f_k = 2^k` 越高，`∇q_k` 越大。

### 1.3 平滑过渡（C1）

把第 k 八度在交界两侧用 smoothstep 权重 `w_k(x)` 混进来，过渡带半宽
`BANDW = 0.35`：

```
w_k(x) = 0                         x ≤ k - BANDW
       = smoothstep((x-k+BANDW)/(2 BANDW))   带内
       = 1                         x ≥ k + BANDW
```

平滑高度场（分子分母同时加权，保持归一化语义）：

```
H(x) = [S_3 + w_3 q_3 + w_4 q_4] / [A_3 + w_3 a_3 + w_4 a_4]
```

带边缘 `w'_k = 0`，故 `H` 跨过带边缘时高度与一阶导数都连续（C1），
导数跳变量 `Δ∇H = 0`；仅二阶导在带边缘不连续。C 侧用单侧有限差分验证
了带边缘的 C0/C1 连续性（见自检 `smooth_C0/C1_at_band_edges`）。

## 2. 三档八度下的法线夹角统计

相邻像素法线夹角，垂直夸张 `Z=3`（统计与渲染口径一致）。每档只统计
两个像素都落在该档内的相邻对，跨交界的对不计入档内统计。

| 档位 | 场 | mean | p95 | p99 | max |
|---|---|---|---|---|---|
| 3 oct | hard | 2.94° | 8.76° | 15.09° | 40.88° |
| 3 oct | smooth | 2.96° | 8.84° | 15.08° | 40.88° |
| 4 oct | hard | 4.95° | 14.98° | 25.26° | 62.70° |
| 4 oct | smooth | 4.97° | 14.91° | 25.49° | 57.42° |
| 5 oct | hard | 9.73° | 30.06° | 49.30° | 96.80° |
| 5 oct | smooth | 9.51° | 29.41° | 48.82° | 98.73° |

八度越多，高频内容使自然粗糙度本身越大（5 档 p95 已接近 30°）。
两套场在档内统计几乎相同，说明平滑过渡没有改变各档自身的粗糙度特征。

## 3. 过渡前后对比（交界 x=3 与 x=4）

解析单侧跳变（C 程序在交界同一点对两侧档位求值，法线用 Z=3）：

| 交界 | 场 | 高度台阶 max | 导数跳变 rms | 单侧法线角 max |
|---|---|---|---|---|
| x=3 (3→4) | hard | 0.1635 | 0.3315 | 123.61° |
| x=3 (3→4) | smooth | 0.00034 | 0.0195 | 8.57° |
| x=4 (4→5) | hard | 0.1001 | 0.3103 | 98.90° |
| x=4 (4→5) | smooth | 0.00022 | 0.0374 | 19.40° |

渲染口径（网格相邻像素法线角，p95；并扣除该档自然粗糙度 p95 作为基线，
得到过渡**额外引入**的夹角）：

| 交界 | hard 带内 p95 | hard 超额 | smooth 带内 p95 | smooth 超额 |
|---|---|---|---|---|
| x=3 | 21.77° | **6.86°** | 11.99° | 0.00° |
| x=4 | 78.85° | **49.44°** | 21.67° | 0.00° |

## 4. 阈值判定

阈值 `5°`，判据为「过渡在自然粗糙度之外额外引入的 p95 法线夹角」：

- 硬截断：x=3 超额 6.86°、x=4 超额 49.44°，**均超阈值，未通过**。
- 平滑过渡：两处超额均为 0.00°（带内 p95 不超过同档自然基线），**通过**。
- **导数跳变量最大的交界：x=4（4→5 八度）**，解析导数跳变 max
  `|Δ∇F| = 1.333`、单侧法线角 max 98.90°。虽然 x=3 的高度台阶更大
  （0.164 vs 0.100），但第 4 八度频率更高（f=16），其斜率项 `∇q_4` 主导，
  使 x=4 的导数/法线跳变反而更大（x=3 解析角峰值 123.61° 更高是个别 y 上
  两侧法线近乎反向的极端点；按 rms 与渲染超额衡量，x=4 的系统性跳变更大：
  导数跳变 rms 0.310 vs 0.331 接近，而渲染超额 49.44° ≫ 6.86°）。
