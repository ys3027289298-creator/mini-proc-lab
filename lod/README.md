# lod

地形细节层级（LOD）策略实验：屏幕空间几何误差 → 层级选择 → 切换频率。
`make test` 跑自检，`make run` 渲染三档层级距离图与两张对比图到 `../artifacts/lod/`。

## 关系式（推导）

层级 l 的网格间距 s_l = s₀·2ˡ，其几何误差 ε_l 为粗网格双线性插值相对全分辨率高度场的最大偏差。
对 fBm 地形（gain=0.5，非光滑），实测 ε 随间距近似幂律：

```
ε_l ≈ C · s_l^α        实测 α ≈ 1.0（ε 每级约 ×2，见下表）
```

投影到屏幕（S=屏高 px，fov 垂直视场角，d=距离）：

```
ρ_l(d) = K · ε_l / d,   K = S / (2·tan(fov/2)) = 345.8 px  (S=360, fov=55°)
```

选层规则「取满足 ρ_l ≤ τ 的最粗层级」直接给出切换距离：

```
d_l = K · ε_l / τ       →  d_{l+1}/d_l = ε_{l+1}/ε_l ≈ 2^α（等比，与 τ 无关）
```

切换频率：相机径向速度 v_r，无滞回时在边界附近每帧抖动都会反复穿越（闪烁根源）。
加滞回比 r（升档阈值 d_l·√r，降档阈值 d_l/√r）后，两次切换的最小行程为滞回带宽度：

```
f_sw ≤ v_r / (d_l·(√r − 1/√r)) = v_r · τ · √r / (K · ε_l · (r−1))
```

切换瞬间的屏幕跳动（pop）：

```
pop_l = K·(ε_{l+1} − ε_l)/d_{l+1} = τ·(1 − ε_l/ε_{l+1}) ≈ τ/2   （与距离无关，只随 τ）
```

结论：τ 同时控制三档误差（ρ≤τ）、切换距离（∝1/τ）、跳动幅度（∝τ）、切换频率（∝τ）；
滞回比 r 只压切换频率（∝1/(r−1)），不增加误差。这就是「远处闪烁、近处太糙」的同一个旋钮：
baseline τ=4 把切换距离拉近（近处只能用到粗层）且允许 4px 的几何跳动（远处闪烁）。

## 三档误差与切换次数（实测，60s 相机路径 @60fps，预算 120 次）

几何误差（ε_l = 粗网格相对 L0 的最大高度偏差）：

| 层级 | 网格间距 | ε_max | ε_rms | 误差比 | 切换距离 τ=4 | 切换距离 τ=1.2 |
|---|---|---|---|---|---|---|
| L1 | 4 m | 0.834 m | 0.119 m | — | 72 m | 240 m |
| L2 | 8 m | 1.791 m | 0.346 m | ×2.15 | 155 m | 516 m |
| L3 | 16 m | 3.372 m | 0.769 m | ×1.88 | 292 m | 972 m |

三档层级距离各渲染一次（tuned 策略）：近 132 m→L0、中 352 m→L1、远 708 m→L2
（`tier_near/mid/far.png`）。

切换时的屏幕跳动：L1↔L2 边界 baseline 2.14 px / tuned 0.64 px；L2↔L3 边界 1.88 / 0.56 px。

切换次数（路径：推进 20s → 回到 L1/L2 边界悬停 25s（±3m 浮沉 + 每帧 ±1.5m 抖动）→ 拉出 10s）：

| 策略 | 总切换 | 推进 | 悬停 | 拉出 | 预算 120 |
|---|---|---|---|---|---|
| baseline τ=4，无滞回 | **215** | 14 | 197 | 4 | **超预算** |
| τ=1.2，无滞回 | 7 | 3 | 0 | 4 | OK |
| tuned τ=1.2 + 滞回 r=1.35 | **5** | 3 | 0 | 2 | OK |

帧间闪烁像素（同一机位，层级按策略在边界 ±4m 重估）：baseline 862 px 变化 / tuned 0 px。

## 切换超预算的妥协方案

baseline 215 次 > 预算 120。按代价从低到高：

1. **加滞回带（零画质代价）**：r=1.35，升/降档阈值拉开 √r 倍。悬停段 197→0。
   代价仅是层级在边界附近多停留 ~16% 的距离行程。
2. **收紧 τ 到 1.2 px**：把切换距离推远 3.3×，近处恢复 L0；切换次数不升反降
   （边界少了反复穿越），代价是近处三角形数 ×4。
3. **顶点 geomorphing**：切换时在滞回带内按 (d − d_l/√r)/带宽 插值顶点高度，
   把残余的 0.64 px 跳动摊成渐变，可允许 τ 再放宽到 ~2 px 换回三角形数。
4. **若仍超预算**：按档分配误差预算（近 τ=1.2、远 τ=3），远处误差被雾和透视压缩，
   人眼不敏感；或冻结远离相机的层级更新（每 N 帧才重估一次远处层级）。

本实验 tuned = 方案 1+2，已达标（5 ≤ 120）；3、4 是进一步省三角形时的后备。
