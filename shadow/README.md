# shadow

把日轨迹投影到高度场上，推导并渲染**山体阴影**（cast shadow + hillshade），在三个时刻各渲染一次，并对阴影长度做独立核验。

推导见 [DERIVATION.md](DERIVATION.md)。

## 构建与自检

```
make test     # 太阳几何、闭式长度、解析算例、真实地形逐块核验
make export   # 自检后再写出 out/*.bin 与 out/*.csv
make          # 只编译
```

## 内容

| 文件 | 内容 |
|---|---|
| `src/shadow.c` | 太阳位置、遮挡步进、阴影/山体阴影渲染、长度实测、全部自检 |
| `DERIVATION.md` | 日轨迹 → 高度场投影、L = dh/tan e 及其坡度推广、实测协议、结果 |
| `tools/make_figures.py` | 读 `out/` 生成三时刻对比图（明/暗）与数值表 |
| `fig_shadow_compare_light.png` / `_dark.png` | 三时刻对比图 |
| `fig_shadow_compare.md` | 对比图的数值表（无障碍替代） |

## 结论摘要

三个时刻（纬度 40°、春分）：

| 时刻 | 方位角 | 高度角 | 阴影覆盖 | 中位长度 | 长度偏差（中位） | ≤20% 占比 |
|---|---|---|---|---|---|---|
| 08:00 | 110.36° | 22.52° | 36.7% | 30.5 m | 4.61% | 93.4% |
| 12:00 | 180.00° | 50.00° | 3.1% | 7.0 m | 5.53% | 91.4% |
| 16:00 | 249.64° | 22.52° | 41.7% | 36.0 m | 4.55% | 85.7% |

- **长度**由高度角决定：L = Δh / tan e；08:00 与 16:00 高度角相同，平地长度严格相等，真实地形的差异来自坡度项 Δh/(tan e + g)。
- **方向**由方位角决定：晨昏反太阳方向相差 139°，两帧阴影 75% 以上互不重叠（Jaccard 0.131）。
- 所有合成算例（台地、平面墙、孤立圆柱）与逐块实测的中位偏差都远低于 20% 判据。

## 约定

- 方位角自北顺时针（北 = 0°、东 = 90°），高度角为地平线以上角度；高度场 +x 朝东、+y 朝北。
- 地形为 256×256 m、格距 1 m 的 fBm 高度场（与 `noise/` 同一套哈希与 fBm，种子 20261124）。
- `out/*.bin` 均为小端 float32 或 uint8，按 `[x*256 + y]` 存放；图脚本会转置成图像朝向。
