# puddle

同一草原区域在三档距离（近 / 中 / 远）下的水洼 LOD 诊断模块，演示
"亚像素存在性 → 覆盖率 → 颜色混合"，对照旧的"存在性多数表决"路径。

## 问题

拉远后粗网格一个格子覆盖多个小水洼。若用存在性（格子内水面积是否
≥ 50%）决定该格是水还是草，小于半格的水洼被整体丢弃，区域平均颜色
随距离变"干"。

## 做法

- 高分辨率参考：512×512 逐点判定，得到真实覆盖率 `coverage_ref`，
  并用"圆盘面积之和"做解析交叉校验（水洼不相交）。
- 每个粗格用 8×8 子采样算水洼覆盖率 `c`：
  - 存在性路径（对照）：`c >= 0.5` 才是水，否则纯草；
  - 覆盖率路径：颜色 `lerp(grass, water, c)`，亚像素水洼折算成色偏。
- 同一片 16×16 世界区域，三档分辨率 256 / 48 / 12，输出每档
  可见水洼数、覆盖率、两条路径的平均颜色与反投影混合比例。
- 诊断：把覆盖率与混合后颜色并列，找出混合比例首先偏离参考值的档。

## 运行

```
make test          # 自检，打印三档统计表与诊断
./puddle <dir>     # 额外把三档 PPM 截图和参考图写入 <dir>
```

拼图（需 PIL，注意用 `-P` 避免脚本目录进入 `sys.path`）：

```
PYTHONPATH=$HOME/.local/lib/python3.12/site-packages \
  python3 -P tools/montage.py <ppm_dir> ../artifacts/puddle_lod.png
```

## 预期诊断（seed=3）

| 档位 | 分辨率 | 可见水洼 | 覆盖率 | 存在性混合比 | 覆盖率混合比 |
|---|---|---|---|---|---|
| near | 256 | 57 | 0.0282 | 0.0281 | 0.0282 |
| mid  | 48  | 30 | 0.0284 | 0.0178 | 0.0284 |
| far  | 12  | 0  | 0.0285 | 0.0000 | 0.0285 |

- 覆盖率在三档守恒（子采样误差 ≤ 容差 0.008），混合路径平均颜色
  与参考一致，不随距离变干。
- 存在性路径**首个超差档是 mid**（混合比 0.0178 vs 覆盖率 0.0282，
  delta ≈ 0.0104），far 档彻底干透（0.0000，全部 57 个水洼消失）。
  对照图：`../artifacts/puddle_lod.png`。
