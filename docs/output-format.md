# 输出格式与复现约定

`worldgen` 只写原始小端二进制，不带元数据头；尺寸由 `meta.txt` 给出。

| 文件 | 类型 | 尺寸 | 说明 |
|---|---|---|---|
| `noise.f32` | float32 | `w*h*4` | 基础高度场 |
| `erosion.f32` | float32 | `w*h*4` | 热侵蚀后的高度场 |
| `biome.u8` | uint8 | `w*h` | 群系编号，见下表 |
| `hydro.f32` | float32 | `w*h*4` | 汇流量（上游格数，从 1 起） |
| `scatter.f32` | uint32 + float32×2n | `4 + 8n` | 点数 n，随后按 (x, y) 交替存放 |
| `meta.txt` | 文本 | — | 主种子、五个子种子、层、线程数、窗口、参数 |

所有栅格都是行优先（先 x 后 y）。窗口 `--window x0,y0,w,h` 的 `(0,0)`
对应世界坐标 `(x0,y0)`。

群系编号：

| 值 | 群系 |
|---:|---|
| 0 | 水域 |
| 1 | 沙漠 |
| 2 | 森林 |
| 3 | 草地 |
| 4 | 苔原 |
| 5 | 岩石 |

## 决定性的来源

1. **同一主种子 → 同一子种子**，见 `docs/seed-derivation.md`。
2. **所有随机量都由世界坐标哈希得到**，不存在“块内计数器”或可变随机流。
3. **侵蚀、汇流都是双缓冲 Jacobi 迭代**：本轮只读上一轮缓冲、只写本轮缓冲，
   同一格的计算不依赖别的线程做到哪一步。
4. **线程按行静态切分**（第 y 行固定属于线程 `y % T`），没有跨线程浮点求和。
5. **散布用“邻域内排名最优先者胜”** 的局部规则，而不是“先到先得”的全局顺序
   拒绝；候选点按格号固定落位，最后按 `(cj, ci)` 顺序串行收集。
6. 编译使用 `-ffp-contract=off -fno-fast-math`，避免编译器把乘加融合成 FMA
   导致同一表达式在不同优化路径下产生不同末位。

## 窗口与接缝

每个层在请求窗口外多算一圈 halo（见 `wg_halo_for_layer`），halo 大小覆盖该
层信息传播的最远距离。所有噪声和阈值扰动都按世界坐标求值，所以窗口结果与
整幅世界在对应区域内**逐位相同**，拼接不会出现断崖。

`--window` 的最外层若落在世界边界，则按世界边界截断，不去读取越界数据。
