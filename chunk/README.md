# chunk

相邻地形块（chunk）之间的缝合：复现接缝裂缝、给出边界采样点重合条件、按条件
统一边界采样，并量化缝合前后的裂缝像素与耗时。

`make test` 跑自检：复现裂缝、在 3×3 块的四处内部交界各验一次、校验共享采样
后裂缝为零。任一处裂缝不为零则退出码为 1。

## 裂缝从哪来

两块相邻、各存一份高度网格时，接缝两侧是**两次独立求值**。只要这两次求值在任一
环节不同，接缝处就会出现高度跳变，即"裂缝"。

本模块按三种布局构建同一地形，其余参数完全相同：

| 模式 | 布局 | 说明 |
|---|---|---|
| `naive` | 每块 `CH*CH`，局部下标 `0..CH-1` | 不存边界列，接缝查询被钳制到倒数第二格，整格错位 |
| `dup` | 每块 `(CH+1)*(CH+1)` | 各块各自复制一份边界列 |
| `shared` | 全网一份 `(N*CH+1)^2` 格点 | 按全局格点下标寻址，边界只有一份 |

裂缝像素定义：接缝上每个采样点（每格 `PPC` 个）按 8 位高度量化后，两侧取值不同的
算 1 个像素。`GRID=3`，四处内部交界，每处 4 条臂、每条臂 `ARM*PPC+1` 个点，
`CH=64, PPC=4, ARM=16` 时每处交界 260 个点。

## 边界采样点重合条件

接缝样本位于全局格点下标 `G`，左块局部下标 `CH`，右块局部下标 `0`，切向参数 `t`
相同。两侧渲染结果逐位相同（裂缝为 0）当且仅当：

- **C1 边界节点存在且可寻址**：左块须保留局部下标 `CH`，右块须保留局部下标 `0`。
  `naive` 只存 `0..CH-1`，接缝查询被钳制到 `CH-1`，差整格。
- **C2 两侧世界坐标逐位相同**：`origin_c + CH*cell` 必须等于 `origin_{c+1} + 0*cell`，
  并且都等于单一路径的规范坐标 `base + G*cell`。**只把下标对齐不够**：各块原点
  `base + c*CH*cell` 各自舍入，两条表达式在部分接缝上会差 1 个 ulp，进而落到不同的
  噪声格点/权重。
- **C3 边界高度逐位相同**：由 C2 直接推出（同一函数、同一实参、确定性哈希），
  于是同一 `t` 的插值结果逐位相同。

C1、C2 是要强制实施的条件，C3 是它们的可观测推论。共享采样通过"只按全局下标
寻址、世界坐标只走 `canon_w()` 一条路径"同时满足三条。

## 实测（`make test` 输出字段）

`cond_boundary_stored` = C1，`cond_same_coord` = C2，`cond_same_value` = C3；
`crack_Jxy` 为交界 `(x,y)` 四臂裂缝像素合计，`crack_total` 为四处之和。

hostile 预设（`base=2^20, cell=0.30`，原点舍入路径确实分叉）：

- `naive`：C1/C2/C3 全 0，四处交界均裂，`crack_total≈978`。
- `dup`：C1 满足、C2 不满足，交界 `(1,1)` 为 0 而其余三处仍裂，`crack_total≈421`。
  这条用来证明 C2 非空——只复制边界值不够。
- `shared`：三条全满足，四处交界 `crack_J11=J21=J12=J22=0`，`crack_total=0`。

benign 预设（`base=0, cell=0.35`，原点恰好一致）：`dup` 也闭合，`naive` 仍裂
（约 1003），`shared` 为 0。说明共享采样不依赖基址巧合。

## 缝合前后耗时

同一进程内三种模式按轮次交错计时，取 40 次中位数，并给出 MAD 作为噪声下限；
差值落在噪声内会显式标注 `(within noise)`。每次构建都是把整张网全部节点求值一遍。

- **构建**：格点数 `shared=37249` 对 `naive=36864`（+1.0%，`naive` 少存一整条边界，
  这正是它裂的原因），对 `dup=38025`（−2.0%）。实际墙钟差通常在毫秒级的 ±0.05 ms
  噪声内，输出会标注 `(within noise)`。
- **接缝查询**：`shared` 每次采样比 `naive` 多约 0.04–0.13 ns（`naive` 少一次跨块
  stride 乘法与原点加法），与 `dup` 基本持平，差值常在噪声内。

绝对量级随机器变化，以 `make test` 现测输出为准。

## 备注

- `-ffast-math`/`-Ofast` 下编译器可以折叠上述两条坐标路径，令 `dup` 的 ulp 分叉
  消失；此时自检跳过 `dup_*` 两条断言并打印 `note=fast_math_skips_dup_insufficiency`，
  其余断言照常。
- 本模块直接复用 `noise/` 的 `fbm`（通过 `noise/src/noise.h`）。
