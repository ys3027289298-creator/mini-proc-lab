# quant

高度场均匀量化 → 高度误差 → 法线误差 → 阴影断裂 的定量分析。`make test` 复现全部数字。

测试场：64×64、cell=1.0、幅度 8.0 的 5 倍频 fBm 值噪声高度场（噪声实现与 `../noise` 同源），
高度跨度 8.8123；太阳方位沿 +x，仰角 10°/20°/30°/45° 四档，射线步进求方向自阴影。

## 1. 量化步长 → 高度误差

中平均匀量化 `h' = δ·round(h/δ)`，量化误差 ε = h' − h：

- 最坏界：`|ε| ≤ δ/2`
- 白噪声模型 ε ~ U(−δ/2, δ/2)：`E[ε²] = δ²/12`，即 rms 高度误差 `σ_h = δ/(2√3) ≈ 0.289δ`

高度误差与步长是**线性**关系。

## 2. 高度误差 → 法线误差（放大倍数推导）

法线由中心差分梯度给出（与 `terrain/field_slope` 同一模板，内部点步距 d = 2·cell）：

```
p = ∂h/∂x ≈ (h(x+d) − h(x−d)) / (2d)
```

两个采样点的量化误差独立有界 |ε| ≤ δ/2，故梯度误差最坏界

```
|e_p| ≤ (δ/2 + δ/2)/d = δ/d          （rms 模型：δ/(√6 d)）
```

即高度到梯度的放大倍数 `|∂p/∂h| = 1/d`：**网格越粗，同样的高度误差被放得越大**。

法线 n = (−p, −q, 1)/√(1+p²+q²)。对一维坡度 s = |∇h|，令 q₀ = δ/d，
取两点误差反向的最坏组合，法线偏角 e 的严格最坏界满足

```
tan e_max = q₀ / (1 + s² − q₀²/4)
```

小误差线性化（q₀ ≪ 1）后：

```
e_max ≈ δ / [d·(1 + s²)]   (弧度)
```

**放大倍数 = 1/[d(1+s²)]，随坡度 s 减小而单调增大，在最平坦处取极限 δ/d。**
这就是量化后平坦区域法线反而最脏、阴影沿平地与缓坡交界处断裂的原因。

## 3. 据法线预算定步长

给定近平坦参考坡度 s₀（内部点坡度的 2% 分位，实测 s₀ = 0.0711）与法线偏角预算 β，
令 q = δ/d，解

```
(tanβ/4)·q² + q − tanβ·(1+s₀²) = 0
```

取正根得 δ。三档预算 β = 2° / 1° / 0.5°，对应三档步长：

| 档位 | 预算 β | δ | 码本级数（跨度/δ） |
|---|---|---|---|
| L0 | 2.0° | 0.03509 | ~252 |
| L1 | 1.0° | 0.01754 | ~503 |
| L2 | 0.5° | 0.00877 | ~1006 |

## 4. 三档实测法线误差（内部 62×62 点）

| 档位 | δ | 高度 rms / max | 法线偏角 rms | 法线偏角 max | 理论界（近平坦 / 最陡 s=1.457） |
|---|---|---|---|---|---|
| L0 | 0.03509 | 0.01017 / 0.01754 | 0.5025° | 1.1971° | 2.000° / 0.644° |
| L1 | 0.01754 | 0.00508 / 0.00877 | 0.2502° | 0.6183° | 1.000° / 0.322° |
| L2 | 0.00877 | 0.00251 / 0.00438 | 0.1241° | 0.3122° | 0.500° / 0.161° |

步长减半，高度 rms 与法线 rms 均近似减半，验证第 1、2 节的线性关系；
高度 max 处处贴住理论界 δ/2，实测最大偏角均落在预算界内。

## 5. 阴影断裂像素计数（全图 4096 像素，状态翻转即断裂）

| 档位 | 太阳10° | 太阳20° | 太阳30° | 太阳45° | 判定 |
|---|---|---|---|---|---|
| L0 | 41 | 23 | 17 | 4 | 未完成 |
| L1 | 20 | 13 | 21 | 4 | 未完成 |
| L2 | 9 | 8 | 9 | 3 | 未完成 |

三档断裂计数均不为零 → **按规则三档全部判未完成**。
计数不随 δ 单调（L1 在 30° 反而比 L0 多），是因为取整网格与阴影边界重新对齐，
属均匀标量量化的固有现象。

继续逐次减半加细，四档仰角全部归零的步长为：

```
δ* = 0.000137（码本 ~64311 级，约 16 bit）
高度 rms=0.000039 max=0.000069，法线 rms=0.0119° max=0.0396°
```

结论：仅靠缩小均匀量化步长保阴影，代价是码本从 ~10 bit 膨胀到 ~16 bit；
工程上应改用误差扩散/抖动量化或对阴影边界做保边处理，而不是无界加细。

## 6. 放大倍数最大的地形区域

角度放大因子 1/√(1+s²) 在坡度最小处最大：

- 8×8 区块统计：block[2,0]，即网格 x∈[16,24)、y∈[0,8)，平均坡度 0.2725，因子 0.9648
- 单点最平坦：网格 (31,29)，坡度 0.00872，因子 0.99996（极限 1.0）

线性增益 |∂p/∂h| = 1/d = 1.0 全场一致；角度放大的空间差异完全由坡度决定，
最平坦的缓坡/台地区域即法线与阴影对量化最敏感的区域。
