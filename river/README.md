# river

由坡度场推导河流网络：流向推导、汇流合并、三档坡度出图、逆坡审计。

## 方法

### 1. 坡度下降方向 → 流向（D8）

连续高度场 h 的最陡下降方向是负梯度 −∇h。离散到 8 邻域格网（D8）：

- 对每个格点 c，计算 8 个邻居 n 的单位距离坡降 `(h_c − h_n) / L_n`，
  正交邻居 L=1，对角邻居 L=√2；
- 流向取坡降最大且严格为正（h_n < h_c）的邻居；无更低邻居的边界格点为出口；
- 并列时按固定罗盘顺序 E,SE,S,SW,W,NW,N,NE 裁决，保证结果可复现。

### 2. 洼地处理（priority-flood）

原始噪声场存在局部洼地，会产生无下游的死角。用 Barnes et al. 2014 的 epsilon 版
priority-flood 从边界向内泛洪：被洼地困住的格点抬升到"入口高程 + ε"，
保证每个内部格点都存在严格更低的下游，且不改变既有分水岭结构。

### 3. 汇流点合并条件

- 按高程从高到低单遍计算汇水面积（每格初值 1，沿流向向下游累加）；
- 格点**入度 ≥ 2** 即两条以上独立支流并入同一链路，判为汇流（入度 1 只是河道延伸）；
- 制图只标**实质汇流点**：入度 ≥ 2 且至少两条入流各自的汇水面积都达到河道阈值
  （RIVER_THRESH=100），排除单点细沟并入的小汇合。
- 汇水面积 ≥ 阈值的格点提取为河道。

### 4. 逆坡流动审计

沿每条流向边核验 `h_下游 < h_上游`；不满足即为逆坡边，内部格点无下游为死角。
出现任一问题判该档**未完成**，并输出问题格点坐标、罗盘方向与上下游高程
（`demo-fault` 模式可人为注入一条逆流验证定位）。

### 三档坡度

同一基础倾斜（向南，水朝 +y 流）叠加不同 fBm，坡度均值严格单调：

| 档 | fBm 层数 | 振幅 | 频率 |
|---|---|---|---|
| gentle 缓坡 | 3 | 5 | 3.5 |
| mid 中坡 | 4 | 8 | 4.5 |
| steep 陡坡 | 6 | 14 | 5.5 |

## 用法

```
make test       # 18 项自检(含填洼、D8、汇流条件、实质汇流过滤、逆坡定位、三档单调性)
make generate   # 三档各出 SVG + ASCII 河道图到 ../artifacts/river/
make fault      # 逆坡演示: 自动选最陡上坡注入逆流, 应判未完成并指出位置 (退出码 2)
```

罗盘方向：0=E 1=SE 2=S 3=SW 4=W 5=NW 6=N 7=NE；`DIR=-1` 自动取目标格点最陡上坡邻居，
指定方向若不构成上坡也会自动回退，局部峰顶则自动改取其他内部格点。

## 产物（artifacts/river/）

- `river_gentle.svg` / `river_mid.svg` / `river_steep.svg`：三档河道图，
  灰阶为高程底图，蓝线为河道，橙环为实质汇流点；
- `river_*.txt`：同口径 ASCII 图（`#` 河道 `o` 汇流 `~` 出口 `.` 其他）；
- `report.txt`：每档坡度、填洼量、逆坡/死角计数、河道形态统计。

## 防"大直道"

河道使用的罗盘流向数与最长同向直段均纳入自检与报告：三档流向数 ≥ 6、
最长直段 ≤ 22 格（80×80 网格），且噪声频率均取 3.5 以上使局部起伏持续拨转流向。
