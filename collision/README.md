# collision

渲染采样与物理碰撞采样不一致的复现、误差上界推导与统一修复。`make test` 跑全量自检。

## 1. 问题模型

同一份程序化高度场（value-noise fBm，参数见 `src/collision.c` 顶部），两条采样路径：

| 路径 | 网格 | 采样位置 |
|---|---|---|
| 渲染 `h_r` | 细网格，间距 `c = 0.5 m`，双线性 | 物体真实位置 `p` |
| 物理 `h_p` | 粗网格，细网格每 `k = 4` 个顶点取一个，间距 `d = kc = 2.0 m`，双线性 | 先把位置吸附到碰撞晶格（间距 `s = 1.0 m`）得到 `p'`，再采样 |

两个误差来源：**位置吸附** `p → p'`（欧氏位移 `|p−p'| ≤ δ = s/√2 = 0.7071 m`，最近格点在对角方向取等号）和**粗网格重建误差**（`d > c`，粗双线性面比细双线性面更平）。

判据：`diff = h_r(p) − h_p(p')`，`diff > ε`（`ε = 1e-5`，吸收浮点舍入）记一次**穿透**（碰撞面低于视觉脚底）；`diff < −ε` 记悬空。

## 2. 误差上界推导

### 界 A：先验解析界（建场之前就成立）

单个 value-noise 八度（晶格频率 `f_n`、振幅 `a_n`）：smoothstep 导数最大 1.5，角点值重映射到 `[−1,1]`，所以每轴偏导
`|∂V/∂x| ≤ 2·1.5·f_n = 3 f_n`，梯度范数 `‖∇V‖ ≤ 3√2 f_n`。
fBm 按 `norm = Σa_n` 归一化、再乘 `HEIGHT_AMP = 6`：

```
L_a = HEIGHT_AMP · 3√2 · (Σ a_n f_n) / (Σ a_n) = 54.3058
```

双线性插值是四个角点的凸组合；单元内一点到四角的加权平均距离在单元中心取最大值 `spacing/√2`。因此 `L`-Lipschitz 场经间距 `g` 的双线性重建，误差 ≤ `Lg/√2`。两段相加：

```
B_a = L_a · (δ + (c + d)/√2) = 134.40
```

### 界 B：实例化场的紧界（建好场后可算）

直接在每个细网格单元上求细双线性面 `h_r` 的梯度范数最大值（每轴偏导是另一参数的仿射函数，凸二次型的最大值在四个参数角点取到），得到 `h_r` 的精确欧氏 Lipschitz 常数 `L_g = 17.0826`。粗网格顶点是细网格顶点的真子集，故在同一公共点 `q`，`h_p(q)` 是 `h_r` 粗角点值的凸组合，`|h_r(q) − h_p(q)| ≤ L_g d/√2`：

```
|h_r(p) − h_p(p')| ≤ |h_r(p) − h_r(p')| + |h_r(p') − h_p(p')|
                   ≤ L_g·δ + L_g·d/√2
B_m = L_g·(δ + d/√2) = 36.2377
```

界 B 不含 `c`：在实例化场上直接比较两个已建曲面，不再经过"重建生成器"这一步。

### 适用条件（两个界共同的前提）

1. 采样点与其吸附像都落在网格**内部**，不触发边界钳制。钳制把双线性降为常数外推，凸组合论证不再成立——自检把测试域限制在粗网格 `[d, (n−1)d − d]` 内，留一整格余量；
2. 粗网格顶点必须与细网格顶点**同一组高度值**（真子集），若两网格分别独立生成/压缩，`L_g d/√2` 项不成立，需另加两网格顶点互差项；
3. 界 A 还要求生成器的解析 Lipschitz 假设成立：固定八度/lacunarity/gain、smoothstep 插值、角点值有界（哈希在 `[0,1)`）。换插值核或加未建模高频项后须重推 `L_a`；
4. 界 B 的 `L_g` 是**该实例场**的测量值，只对这个 seed/参数组合有效；换 seed 要重测，或退回界 A；
5 吸附用最近格点（圆整），位移界 `s/√2`；换吸附策略（如 floor）位移界变为 `s`；
6. 界管的是高度标量差的绝对值；实际穿透判定带 `ε = 1e-5` 浮点容差，界本身不含舍入项。

## 3. 统一采样点

修复：物理侧不再维护独立粗网格、不再吸附位置，与渲染侧调用**同一个细网格采样器、同一个世界坐标** `fine_sample(p)`。两条路径输入与函数完全相同，高度差恒为 0（位级一致），穿透从结构上不可能发生。

## 4. 实测结果（`make test`）

误差上界：`B_a = 134.40`（先验）、`B_m = 36.2377`（实例化），200×200 内点扫描的经验最差误差 `7.0991`，满足 `worst ≤ B_m ≤ B_a`（独立 Python 复算核对一致）。

三档位置（按渲染高度三分位各取一个代表点，优先取穿透点）统一前高度差 `h_r − h_p`：

| 档位 | 位置 p | 吸附 p' | h_render | h_phys | 高度差 | 状态 |
|---|---|---|---|---|---|---|
| low | (5.015, 7.528) | (5, 8) | −4.5567 | 0.4684 | −5.0251 | 悬空 |
| mid | (11.548, 5.518) | (12, 6) | 1.1912 | −3.2284 | +4.4197 | 穿透 |
| high | (10.995, 5.518) | (11, 6) | 4.3244 | −2.7747 | +7.0991 | 穿透 |

三点高度差均在 `B_m` 内（检查项 `three_diff_inside_Bm=1`）。

穿透计数（`ε = 1e-5`）：

| 审计对象 | 统一前穿透 | 统一后穿透 |
|---|---|---|
| 三档位置 | 2 | **0** |
| 100 个抖动散布物体 | 60（另有 40 悬空） | **0** |

所有检查项 `all_ok=1`；统一后穿透不为零即判未完成，当前为零。
