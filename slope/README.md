# slope

把"草长在陡坡上"这件事变成可以拟合、可以检验的量：先给出坡度–散布密度衰减的函数形式，用实测数据拟合参数并给出置信区间，再按坡度分层统计；部署参数落在区间外即判定不通过。

```
make            # 构建 libslope.a 与 tools/slope_fit_report
make test       # 自检（拟合、区间覆盖率、分层、判定）
make report     # 内建标定数据跑完整报告
make report ARGS='--csv survey.csv --rho0 ... --s0 ... --p ...'
```

## 1. 函数形式

散布密度随坡度 `s`（rise/run，即高度差除以水平距离）衰减：

```
rho(s) = rho0 * exp( -(s / s0)^p )
```

- `rho0`：平地保留率，即零坡度处相对候选网格的密度，取值 (0, 1]。
- `s0`：坡度尺度，`rho` 降到 `rho0/e` 时的坡度。
- `p`：形状指数。`p = 1` 是指数衰减，`p = 2` 接近 Rayleigh/高斯衰减，`p` 越大，平缓段保持得越久、之后跌得越陡。

选它的理由：`rho0` 与 `s0` 都能直接读懂；`p` 把"从哪一段开始明显变稀"和"变稀得多快"分开；`p = 1` 时退化成一个参数的指数律，便于用似然比检验判断多出来的形状参数是否值得。

报告同时拟合两个备选形式做对照，按 AICc 选优：

| 模型 | 形式 | 参数个数 |
|---|---|---|
| `exp` | `rho0 * exp(-(s/s0))` | 2 |
| `stretched` | `rho0 * exp(-(s/s0)^p)` | 3 |
| `hill` | `rho0 / (1 + (s/s0)^p)` | 3 |

## 2. 拟合与置信区间

每个坡度分箱给出 `(平均坡度, 候选数 m, 保留数 k)`，按二项似然拟合：

```
nll = -sum[ k*log(rho(s)) + (m-k)*log(1-rho(s)) ]
```

优化在无约束空间做（`logit(rho0)`, `log s0`, `log p`），Nelder–Mead，多起点网格，避免落入局部极值。

置信区间用**剖面似然**而非 Wald 近似：固定待求参数，重优化其余参数，找到似然比统计量 `2*(nll - nll_min)` 越过 `chi2(1)` 分位点（95% 时为 3.841）的位置。参数在边界处（例如 `rho0 -> 1`）或形状参数高度相关时，Wald 区间会严重失真，剖面区间仍然成立。报告中的 `std.err` 由区间宽度换算，仅作参考。

`make test` 中的覆盖率回归用例：同一真值重复抽样 10 次，要求三个参数的区间各自至少覆盖 8 次。

## 3. 按坡度分层统计

固定三层，边界为 0.50 与 1.00（约 26.6° 与 45°）：

| 层 | 坡度范围 |
|---|---|
| 缓坡 | [0, 0.50) |
| 中坡 | [0.50, 1.00) |
| 陡坡 | [1.00, +inf) |

每层给出候选数、保留数、实测密度（附 Wilson 95% 区间）、模型预测密度、残差，以及观测数与预测数差异的正态检验 p 值。p 值用来发现"整体拟合过得去、但某一层系统性偏离"的情况，这正是陡坡仍然长草的直接诊断。

## 4. 上线判定

```
./tools/slope_fit_report --rho0 R --s0 S --p P
```

把待上线参数与拟合得到的置信区间逐项比较（区间端点算通过）：

- 全部落在区间内：`PASS`，退出码 0；
- 任一参数落在区间外：`FAIL`，打印越界的参数与区间，退出码 1，**不通过**。

不传参数时按当前"无衰减"行为（`rho0 = 1, s0 = 1e9, p = 1`）检验，因此内建标定数据下报告固定给出 `FAIL`——这正是要修的问题。

## 5. 数据来源

- `--csv PATH`：实测数据，每行 `坡度,候选数,保留数`，允许 `#` 注释行与表头。
- 默认（`--fixture`）：内建标定数据。它用地形模块生成高度场，按已知真值 `rho0=0.92, s0=0.55, p=1.5` 驱动散布模块抽样，再走完整拟合流程，用来验证拟合器与区间估计的正确性（拟合结果回到 0.915 / 0.553 / 1.507，真值均落在区间内）。

**内建数据只是标定用的合成数据，不是实测。** 生产结论必须用 `--csv` 喂入实测分层计数。

## 6. 已知取舍

- 分箱用箱内平均坡度作为代表点。密度对坡度是凸的，用 `rho(平均坡度)` 代替箱内平均值会有向上偏倚，因此标定数据额外累计了逐候选的期望值并在报告里核对；实测 CSV 只有计数，偏倚随分箱变窄而缩小，报告默认 0.01 一档。
- 散布模块的候选哈希按二维坐标生成，抖动与保留判定两个随机数相互独立（`scatter/tests/test_internal.c` 有回归断言）。
