# warp

域扭曲（domain warp）把过直的地形边线扭弯，幅度上限由推导给出，防止糊化。

## 推导

扭曲映射 `w(p) = p + A·q(p)`，`q = (g1, g2)` 为 [-1,1] 的 fBm 向量场，
记 `Lq = max‖J_q‖`（q 的雅可比谱范数上界），`G_H = max|∇H|`（基场梯度上限）。

**幅度 ↔ 特征失真**：位移 `d(p) = A·q(p)`，`|d| ≤ √2·A`；邻近点相对位移
（应变）`ε(A) = A·Lq`，与 A 成线性。尺度为 s 的特征变形 ≤ ε·s；
`A·Lq ≥ 1` 时映射可能折叠（非单射）→ 糊。要求 `ε ≤ ε_max`。

**扭曲后梯度上限**：`∇F = J_wᵀ∇H`，`J_w = I + A·J_q`，故
`|∇F| ≤ G_H·(1 + A·Lq)`。网格 cell 为 h 时可分辨梯度上限 `G_allow = 1/(2h)`。

**幅度上限**（三者取最小）：

```
A_max = min( ε_max / Lq,                       # 应变（防折叠）
             D_max · λ_min / √2,               # 位移不超过最小特征的 D_max 倍
             (G_allow/G_H − 1) / Lq )          # 梯度不超过网格可分辨范围
```

fBm 的解析上界 `Lq ≤ 6·O_w·ω`（每倍频程 `|∂n/∂x| ≤ 3f`，向量场再乘 √2），
程序同时输出数值实测的 `Lq` 并用实测值定上限，运行时自检应变、梯度、
位移三项约束全部满足才算通过。

## 用法

`make test` 在 0、1/3、2/3、1 倍 A_max 下各生成一张图（`out/*.bmp`），
打印边线弯曲度（marching squares 提取海岸线，重采样后量平均/最大曲率、
弧弦比）并自检上述约束。
