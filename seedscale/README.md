# seedscale — 种子与特征尺度的独立性

`noise/` 里的值噪声换种子后"地貌特征全变"是预期行为（换的就是随机场实现），
但**特征尺度**（相关长度、方差、频谱形状、各向同性度）不应随种子变化。
本目录给出：

1. 独立性条件的形式化推导（C1–C3）；
2. 满足条件的哈希构造 `ss_hash2`（`src/hash.h`）；
3. 三档种子下的特征统计与三层独立性检验；
4. 三个故意做坏的对照组，证明检验能区分**哈希问题**与**采样问题**。

```
make test     # 哈希级检验（good 应全过）
make stats    # 五组场级实验 -> out/*.csv
python3 -I analyze.py out out/report.txt
```

## 1. 条件推导

### 1.1 管线形式化

二维值噪声高度场写成三层：

```
晶格白噪声:  W_s(i,j) = u01(H(i,j,s))          i,j ∈ Z²,  s ∈ S 为种子
连续场:      f_s(x,y) = Σ_{i,j} W_s(i,j) K(x-i, y-j)
采样:        g_s[n,m] = f_s(x0 + nΔ, y0 + mΔ)
```

`K` 是双线性 smoothstep 插值核，紧支在单位格 `[0,1]²` 上。地貌的"特征尺度"
完全由场的二阶统计量决定，即自相关

```
R_s(τ) = E_{x}[ f_s(x) f_s(x+τ) ]。
```

"种子与特征尺度独立"的精确表述：**R_s 不依赖 s**（一阶矩同理），即对任意
种子 s、s′ 有 R_s = R_{s′}。

### 1.2 充分条件

把要求分解为三条可检验的充分条件：

- **C1 白晶格（空间独立同分布）**：对每个固定 s，族 `{W_s(i,j)}` 是 i.i.d.，
  且分布 F 与 (i,j,s) 无关。
- **C2 种子只选实现、不选尺度**：种子只允许出现在 H 的"实现选择"位置
  （加法置换项），不得进入坐标系数、格距 Δ、核 K、频率/八度参数。
- **C3 采样端与种子无关且满足采样定理**：Δ、(x0,y0)、插值核不随 s 变化，
  且场的有效带宽 B < 1/(2Δ)。

推导（自相关展开）：

```
R_s(τ) = E_x Σ_{i,j} Σ_{i′,j′}
           W_s(i,j) W_s(i′,j′) K(x-c_ij) K(x+τ-c_i′j′)
```

- C1 使交叉项期望 `E[W(i,j)W(i′,j′)] = σ²·δ_{(i,j),(i′,j′)}`，双重求和塌缩为
  单重求和 `R_s(τ) = σ² Σ_{i,j} K(z) K(z+τ)`——**式中已不含 s、不含格点位置**，
  只由核 K 与方差 σ² 决定；
- C2 保证换种子只对 i.i.d. 序列做一次重新抽样（实现置换），F、σ²、K、Δ 均不变，
  故 R_s 对所有 s 恒等；
- C3 保证离散采样 g 的自相关是 R_s 的无混叠拷贝；否则混叠项依赖场的具体相位，
  尺度信息被采样污染。破坏 C3 不会改变"同一种子内部"的 R_s 理论形式，但会让
  实测谱在 Nyquist 以上长出与实现相关的假能量。

必要的反例（每个条件单独破坏的后果，均由实验复现）：

| 破坏条件 | 做法 | 后果 |
|---|---|---|
| C1 | 哈希无终混、格点代数相关（`bad-linear`） | 跨格点相关非零；加法种子项还会被插值核整体减掉，换种子不换场 |
| C2 | 种子低 3 位乘进采样坐标（`sx` 模式） | 相关长度随种子位成组变化，三档边缘分布却几乎相同 |
| C3 | 最近邻采样（`nn` 模式） | 方波跳变把能量抛到 Nyquist 以上，高频能量比显著升高 |

### 1.3 对 C1/C2 的代数要求（落到哈希函数上）

在模 2^64 整数域上，要让"种子只做实现选择"，需要：

1. 固定 (i,j) 时，映射 s ↦ H(i,j,s) 是双射——每个种子对应晶格上的一个均匀置换，
   这要求种子以**加法**进入状态字 `a(i,j)+s`（乘法则需要可逆乘法常数，奇数即可）；
2. 状态字到输出的终混是双射且满足全雪崩（任一输入比特翻转 → 每个输出比特以
   1/2 概率翻转），保证 C1 的 i.i.d. 近似；
3. 坐标常数与种子常数在代数上独立（不共享因子、不含随 s 变化的系数），保证 C2。

## 2. 哈希构造（`src/hash.h`）

```c
state = i*P1 + j*P2 + s              (mod 2^64)
H     = splitmix64_finalizer(state)
```

- `P1, P2` 为奇数 64 位常数 ⇒ 坐标映射在模 2^64 下可逆；
- 种子仅以 `+s` 出现 ⇒ 固定格点上 s↦state 是平移双射，再经双射终混仍为双射
  （满足 1.3 的要求 1）；
- SplitMix64 终混是两轮乘加异或移位，对 uint64 是双射且实测全雪崩（要求 2）；
- 哈希内部没有任何长度/尺度量，尺度只由采样端格距引入（要求 3，即 C2）；
- fBm 八度号以独立奇数常数 `o*OCT` 加法进入，每八度内仍保持种子双射。

## 3. 三档种子与实验设置

| 档 | 种子集合（每档 128 个） | 意图 |
|---|---|---|
| S 小整数 | `0..127` | 最易暴露低位缺陷、线性相关 |
| M 中档 | `2^16 + k*101` | 固定高位、变化中低位 |
| L 全 uint32 | 固定主种子 PRNG 抽取 | 覆盖整个 32 位种子空间 |

每场 32×32 晶格、8 点/格（256×256）、周期环绕；特征：方差、1/e 相关长度
（格与像素两种单位）、各向同性度、零交叉游程、零交叉数、高频能量比 hf
（波数 > 晶格 Nyquist 的 2D 谱功率占比），以及横/纵方向 0..32 像素滞后自相关。

## 4. 三层检验

- **哈希级 `hash_test`**（每档同跑）：满置换单射、256 桶 χ² 均匀性、64 比特
  平衡、i/j/s 三路雪崩、相邻格点值相关与比特相关、x/y 各向同性。
- **H1 跨种子独立性（场级）**：档内相邻种子场的 Pearson 互相关应 ~0
  （单样本 t 检验，Bonferroni 校正）。
- **H2 尺度独立性·跨档**：六个特征在三档间做 Kruskal-Wallis 检验，并报告
  跨档均值漂移（合并 sd 为单位，阈值 0.5）。
- **H3 尺度独立性·档内**：按种子低 3 位分 8 组对相关长度/hf 做 KW。
  H2 只比较三档边缘分布，会被"每档内部都同样耦合"骗过；H3 直接查种子位与
  尺度的系统性耦合。

## 5. 结果与失效归因

完整数字见 `out/report.txt`（由 `analyze.py` 生成）。汇总：

| 配置 | 哈希级 | H1 | H2 | H3 | hf | 归因 |
|---|---|---|---|---|---|---|
| good + 值噪声 | 全过 | PASS | PASS | PASS | 0.242 | 合格基线 |
| good + fBm 4 八度 | 全过 | PASS | PASS | PASS | 0.376 | 合格（高频是八度内容，按同八度阈值判） |
| good + 最近邻 `nn` | 全过 | PASS | PASS | PASS | **0.486** | **采样问题**：仅 hf 超同八度阈值 |
| good + 种子耦合频率 `sx` | 全过 | PASS | PASS | **FAIL** (p≈1e-27) | 0.820 | **C2 违反**：尺度随种子低 3 位成组变化 |
| `bad-linear` + 值噪声 | 雪崩/均匀/相邻/各向同性全挂 | **FAIL** (xcorr 0.99) | FAIL | FAIL | 0.340 | **哈希问题**：所有种子产出同一场，档内 sd=0 |

归因规则（检验不通过时如何区分哈希还是采样）：

1. 哈希级先验筛选挂 ⇒ 哈希缺陷，场级不用看；
2. 哈希级过、H1 挂（场间相关或零方差）⇒ 哈希引入跨格点/跨种子结构，哈希问题；
3. H1 过、H3 挂且相关长度等尺度指标随种子位分组 ⇒ 种子被耦合进尺度，
   属管线/哈希构造违反 C2（`sx` 实验证明此症只能在采样坐标层产生，
   纯哈希值层重标号改不动几何尺度）；
4. H1/H2/H3 全过、只有 hf 超**同八度**基线阈值 ⇒ 采样端混叠，采样问题。

关键数字（good 基线，三档 mean±sd，128 种子/档）：

- 相关长度 `0.7604 / 0.7639 / 0.7625` 格，跨档漂移仅 0.18 个合并 sd；
- 方差 `0.1831 / 0.1845 / 0.1838`；
- 相邻种子场互相关 `|xcorr| < 0.006`，三档均不显著（p ≥ 0.052）；
- 平均自相关曲线三档最大偏差 0.0072。
